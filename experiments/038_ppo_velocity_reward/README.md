# 实验 038：只改变 PPO 训练中的近目标速度奖励

## 问题与假设

实验 037 的典型失败轨迹在目标附近仍保持较高速度，正目标还出现很晚才反向的动作。环境原奖励为 `-距离 - 0.01×动作²`，而任务成功还要求速度足够低。本实验检验：给训练奖励增加一项近目标速度惩罚，是否改善闭环停稳。轨迹现象只是提出假设，不是证明奖励就是根因。

## 唯一改动

```text
近目标权重 = max(0, 1 - abs(目标误差) / 0.5)
训练奖励 = 环境原奖励 - 0.5 × 近目标权重 × abs(下一状态速度)
```

原组速度项权重为 `0`。两组使用完全相同的实验 037 环境参数、三档动作、模型结构、训练 seed 37–196、20 次更新、每次 8 条 Episode、优化设置与评价 seed 100037–100056。训练轨迹随策略更新可能分叉，不能说两组采到了完全相同的数据。评价时一律使用原环境奖励与成功条件，不把速度惩罚混进测试分数。

## 预先约定的判断

- 主要观察：正目标独立成功数能否从 0/10 增加，以及总成功数能否超过原来的 6/20。
- 同时检查：原环境平均回报、最终距离、负目标成功数有无恶化。
- 只试这一个权重与半径，不根据结果重选评价 seed 或事后挑选更好超参数。单训练 seed 和 20 个评价任务只支持本次受控观察。

## 运行

```bash
conda activate robot_learning
cd ~/AI_Project/robot-learning
PYTHONPATH=src python -m pytest -q tests/test_ppo_training.py tests/test_ppo_clipping.py
PYTHONPATH=src python experiments/038_ppo_velocity_reward/run.py

```

输出在忽略 Git 的 `outputs/038_ppo_velocity_reward/`，包含两组训练历史、原始奖励的独立评价汇总和逐条评价记录。P 控制器与随机策略仍以相同 seed 对照。

## 结果

两组使用相同训练预算和独立评价任务。原奖励组的 20 条逐条评价记录与实验 037 完全一致；新组的训练速度惩罚实际非零，且测试确认其进入价值学习目标，评价仍使用原环境奖励。

| 策略或条件 | 独立成功数 | 正目标成功 | 负目标成功 | 平均原环境回报 | 平均最终距离 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原奖励 PPO | 6/20 | 0/10 | 6/10 | -388.11 | 1.653 m |
| 近目标速度惩罚 PPO | 0/20 | 0/10 | 0/10 | -519.52 | 1.974 m |
| 随机策略 | 0/20 | — | — | -356.87 | 1.561 m |
| P 控制器 | 20/20 | — | — | -59.16 | 0.030 m |

预先约定的主要指标均未改善：正目标仍是 0/10，总成功数由 6/20 降到 0/20；原环境回报和最终距离也变差。新组负目标的 10 条评价轨迹中，有 7 条终点甚至位于原点右侧，而目标在左侧。这说明本次固定权重 `0.5` 的塑形并未解决已观察到的制动问题，还可能改变了策略方向；但单训练 seed 无法支持“速度惩罚普遍有害”或某个具体机制的结论。

本次保留负结果，不在同一实验中改权重、训练预算或评价 seed 来寻找更好的数字。PPO/奖励与环境相关测试已通过，但代码运行正确不等于策略有效。

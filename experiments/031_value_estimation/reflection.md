# 实验反思

## 实验问题

一次轨迹 Return 为什么不能直接等同于 Value？本实验保留真实答案，通过增加采样量观察估计值如何变化，避免把某次随机结果误认为价值函数本身。

## 结果

手工计算得到 `Q_safe=1.0`、`Q_risky=1.8`。当前策略以 75% 选择 safe、25% 选择 risky，因此 `V=1.2`，对应 `A_safe=-0.2`、`A_risky=0.6`。策略概率加权后的 Advantage 约为 0，浮点残差为 `5.55e-17`。

固定随机种子后，10 次采样只有 2 次 risky，成功和失败相互抵消，使 `Q_risky` 被估计为 0；100 次时仍只有 0.470。到 1000 和 10000 次时分别为 1.690 和 1.835，逐渐接近真实值 1.8。V 的绝对误差相应从 0.400 降至 0.012。

少量样本不只是让数值不准，还可能把 Advantage 的正负号估错，从而让策略更新朝错误方向移动。这是后续需要 Critic、批量采样、Advantage 标准化和 GAE 等降方差方法的直接动机；当前尚未验证这些方法。

## 当前边界

本实验使用样本平均，没有训练价值网络，也没有实现 TD、GAE 或 PPO。它验证的是这些算法依赖的目标含义，不是策略优化结果。

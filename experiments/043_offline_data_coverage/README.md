# 实验 043：固定数据的动作覆盖对照

## 要解决的问题

[实验 042](../042_offline_q_extrapolation/README.md) 中，`S1` 的动作 1 没有训练数据，任意设定的 `Q=5` 被普通 TD 目标传给了 `S0`。这里检查更窄的假设：**如果在训练开始前，固定数据已经包含这个动作的一条真实转移，会发生什么？**

三组使用相同的初始 Q 表、`γ=0.9`、学习率 `1` 和两条共有转移：

```text
S0 --动作0, 奖励0--> S1
S1 --动作0, 奖励1--> 终止
```

只有第三条**预先收集**的转移不同：第一组没有 `S1,动作1`；第二组有且奖励为 `0`；第三组有且奖励为 `10`。所有 `S1` 动作在这个两状态例子中都立即终止。训练过程不调用环境、不追加数据，先更新数据中存在的 `S1` 转移，再对共有的 `S0,动作0` 做普通 `max Q` 更新。

## 运行与结果

```bash
conda activate robot_learning
PYTHONPATH=src python experiments/043_offline_data_coverage/run.py
```

| 固定数据对 `S1,动作1` 的覆盖 | 更新后 `Q(S1,动作1)` | `S0,动作0` 的 TD 目标 |
| --- | ---: | ---: |
| 无记录 | 5（未验证初值） | `0.9 × max(1,5) = 4.5` |
| 一条奖励 0 的记录 | 0 | `0.9 × max(1,0) = 0.9` |
| 一条奖励 10 的记录 | 10 | `0.9 × max(1,10) = 9.0` |

配置见 `configs/043_offline_data_coverage.json`；逐条件数据与实际运行结果保存在被 Git 忽略的 `outputs/043_offline_data_coverage/results.json`。

实际运行得到表中的 `4.5 / 0.9 / 9.0`，程序检查了三组共有转移一致、覆盖组各有一条动作 1 记录。复用的 Q-Learning 与 TD 单元测试运行 `11 passed`；这是代码机制检查，不是离线策略的独立闭环评价。

## 能说明什么、不能说明什么

在这个人为确定、终止奖励可由一条转移直接观察的小任务中，覆盖 `S1,动作1` 后，普通 TD 目标不再依赖它未经验证的初值。覆盖数据为 0 或 10 时，结果不同；**离线数据本身决定了能判断什么，不是“限制动作”一定更优。** 现实中的随机奖励、连续动作、长轨迹和神经网络泛化通常不能靠一条样本解决。这里验证的是数据覆盖机制，不是完整离线 RL 方法、闭环成功率或真机性能。

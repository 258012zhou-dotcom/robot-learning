# 实验 028：受控扰动与分布偏移

## 目标

在不重新训练策略的情况下，把 P 控制专家和实验 027 的 BC 策略短暂推离原有执行轨迹，比较两者恢复能力。实验用于判断当前简单任务中是否存在“专家能恢复、BC 不能恢复”的状态区域，再决定是否需要实现 DAgger。

## 扰动设计

- 使用训练数据未见过的 seed 4000–4099，共 100 个 Episode。
- 第 50 个控制步开始，暂时覆盖策略动作。
- 覆盖动作为沿目标方向的最大动作，目的是增加速度和过冲。
- 持续时间分别为 0、5、10、20、40 步；0 步是配对无扰动基线。
- 每个策略、每个条件使用完全相同的 seed 和目标。

这里研究的是一次可观测状态偏离后的恢复，不是传感器偏差、持续动作延迟或动力学参数变化。后几类问题可能同时削弱专家，不能直接归因于 BC 数据覆盖不足。

## 运行

先完成实验 027 并生成 checkpoint，然后执行：

```bash
conda activate robot_learning
cd ~/AI_Project/robot-learning
PYTHONPATH=src python -m pytest -q tests/test_distribution_shift.py tests/test_behavior_cloning.py tests/test_gymnasium_rollout.py
PYTHONPATH=src python experiments/028_distribution_shift/run.py
python -m json.tool outputs/028_distribution_shift/results.json
PYTHONPATH=src python experiments/028_distribution_shift/analyze_velocity_sensitivity.py
python -m json.tool outputs/028_distribution_shift/velocity_sensitivity.json
```

`results.json` 包含逐 Episode 原始指标及相对无扰动基线的步数、回报变化；`velocity_sensitivity.json` 保存固定误差、只改变速度时的专家与 BC 动作。生成结果不提交 Git。

## 当前状态

第一轮受控扰动评价已完成。100 个目标恰好包含 50 个正方向和 50 个负方向；所有 Episode 都准确执行了配置的动作覆盖步数。

| 覆盖持续时间 | P 控制成功率 | BC 成功率 | P 平均步数 | BC 平均步数 |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 100% | 100% | 227.4 | 224.7 |
| 5 | 100% | 100% | 274.2 | 284.7 |
| 10 | 100% | 100% | 315.0 | 315.7 |
| 20 | 79% | 100% | 350.8 | 345.2 |
| 40 | 0% | 0% | 400.0 | 400.0 |

随着覆盖持续时间增加，两种策略的过冲和恢复时间都上升。但没有出现“P 控制专家能恢复、BC 不能恢复”的条件：20 步覆盖时 BC 反而全部成功，40 步覆盖时两者都失败。

因此当前结果不支持在这个简单任务上直接增加 DAgger。它也不证明 BC 普遍比 P 控制更稳健；需要进一步检查 BC 是否在专家数据中的相关特征上学到了非预期的速度依赖，才能解释 20 步条件的差异。

## 速度敏感性检查

固定位置为 0，并保持目标误差不变，只把速度从 -2.0 扫描到 2.0。P 控制专家只使用目标误差，因此每组动作跨度都是 0；BC 的动作会随速度变化。

| 目标误差 | BC 训练速度范围内动作跨度 | BC 完整扫描动作跨度 |
| ---: | ---: | ---: |
| -1.50 | 0.0476 | 0.1306 |
| -1.00 | 0.0249 | 0.2164 |
| -0.50 | 0.0400 | 0.1445 |
| -0.25 | 0.0318 | 0.1371 |
| +0.25 | 0.0385 | 0.2662 |
| +0.50 | 0.0506 | 0.3257 |
| +1.00 | 0.0901 | 0.2971 |
| +1.50 | 0.0356 | 0.1652 |

这说明 BC 并没有精确复现专家的决策规则。训练数据中的速度与目标误差来自同一批闭环轨迹，两者存在相关性；网络即使取得较低测试 MSE，也可能利用速度这一非必要特征。超出训练速度范围后差异通常更明显。

这个发现与 20 步扰动中 BC 和专家行为不同相符，但不能单凭动作扫描断言它就是成功率差异的唯一原因。下一步将训练一个只接收目标误差的 BC，做受控消融比较。

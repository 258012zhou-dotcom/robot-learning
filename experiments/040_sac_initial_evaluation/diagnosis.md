# 实验 040 补充诊断：负目标数据是否进入更新

## 问题与方法

上一轮训练后 SAC 在 20 个独立任务中成功 `0/20`，11 个负目标任务全在正方向结束。本诊断不改训练算法、配置、种子、奖励、环境或采样顺序，只用一个回放池子类给每次 `sample()` 返回的 batch 计数，并检查保留下来的训练轨迹。

运行：

```bash
conda activate robot_learning
cd ~/AI_Project/robot-learning
PYTHONPATH=src python experiments/040_sac_initial_evaluation/diagnose_training.py
```

诊断重跑的 `240` 环境步、`176` 次更新、回放池大小、末次 Actor/Critic 损失均与实验 040 的原训练报告匹配；脚本将此核对结果写为 `reference_training_matches: true`。详细计数保存在忽略 Git 的 [`training_diagnosis.json`](../../outputs/040_sac_initial_evaluation/training_diagnosis.json)。

## 观察

| 项目 | 实测 |
| --- | ---: |
| 收集的正目标转移 | 200 条，第一回合超时 |
| 收集的负目标转移 | 40 条，第二回合尚未结束 |
| batch 总抽样次数 | 11,264 次 = 176 次更新 × 64 |
| 正目标抽样次数 | 11,039 次 |
| 负目标抽样次数 | 225 次，约 2.0% |
| 含负目标的更新 | 38/176 次；第一次是第 137 次 |

`225` 是有放回抽样的**抽取次数**，不代表 225 条不同转移。负目标轨迹的 40 个实际动作中，正动作 19 个、负动作 21 个，平均动作约 `+0.054`；因此不能说采样训练时“从未向负方向施力”。但同一负目标起点在确定性评价下，Actor 输出从训练前约 `+0.002` 变为训练后约 `+0.186`，方向确实偏正。负目标训练片段只持续 40 步，最终位置约 `+0.056 m`；独立评价是最多 200 步，不能把两者终点直接比较。

## 结论与下一步

已验证：负目标经验**没有被完全排除**，但前 136 次更新只看过正目标，整个训练的负目标抽样仅约 2%。这与训练后负目标能力差相一致，却不能单独证明是唯一原因。也不能把正目标 `0/9` 失败完全归因于方向覆盖；它还可能涉及预算、探索、超参数或优化细节。

下一步若要检验“目标方向覆盖不足”这个解释，应预先固定更均衡的训练任务，再保持评价任务、网络、奖励及其他超参数不变做对照；不要仅凭本诊断就宣称找到根因或认定 SAC 无效。

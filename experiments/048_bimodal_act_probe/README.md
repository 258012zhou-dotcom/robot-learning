# 实验 048：同一观察、两种动作的 ACT 教学探针

## 目标与原理

人工构造两条完全相同观察的示范：一条未来 4 步动作均为 `−0.8`，另一条均为 `+0.8`。这样观察本身不含“选左还是选右”的信息，只有训练后验能看到对应的示范动作。检查训练后的后验均值能否编码两种示范，以及默认 `z=0` 推理能否同时区分它们。

这是**仅两条合成样本的机制教学检查**。不是环境仿真轨迹、独立测试集、闭环控制或 ACT 论文复现。它不能证明模型在真实多模态任务上的表现。

## 验证

单元测试确认两个观察完全相同、动作方向相反且掩码均有效；参数无效时抛错。运行脚本固定随机种子和训练步数，记录两个示范的后验均值、用各自后验均值解码的动作、默认 `z=0` 动作以及重建误差。

```bash
PYTHONPATH=src /home/zxd/miniconda3/envs/robot_learning/bin/python -m pytest -q tests/test_act_bimodal_probe.py tests/test_act_lowdim.py
PYTHONPATH=src /home/zxd/miniconda3/envs/robot_learning/bin/python experiments/048_bimodal_act_probe/run.py
```

配置见 `configs/048_bimodal_act_probe.json`，输出在 Git 忽略的 `outputs/048_bimodal_act_probe/`。

## 实际结果与边界

2026-09-27，seed 42、固定 500 个全批次训练步。两条训练示范的后验均值分别约为 `[-2.02, -0.54]` 和 `[2.30, 0.19]`。用各自的后验均值解码，四步动作分别约为 `−0.81` 和 `+0.80`，与目标 `−0.8`、`+0.8` 接近；两条示范的平均绝对重建误差分别为 `0.0118`、`0.00183`。最终两样本平均 KL 约 `3.10`，不再像实验 047 那样接近零。

默认推理固定 `z=0` 时，两条相同观察得到完全相同的动作片段：`[0.062, 0.098, 0.059, 0.086]`。它处于两种示范之间，既不是左走也不是右走；对左右目标的平均绝对误差分别为 `0.876`、`0.724`。这**只说明当前合成例子的默认推理不具备路线选择信息**，不意味着 ACT 在所有多模态数据上必然输出折中动作。输出中保留完整数值和训练快照，可在 `outputs/048_bimodal_act_probe/results.json` 核对。

两条样本反复训练且训练后验直接看到目标动作，所谓“后验重建好”不是泛化能力证据；这里没有独立验证集、真实环境、任务成功率或实际选择左/右路线的闭环机制。要在执行时稳定选择路线，需要让观察或任务指令包含选择信息，或另设计采样与评价/选择机制；原样固定 `z=0` 不能从完全相同的观察推断出示范者这次的隐含意图。

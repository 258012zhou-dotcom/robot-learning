# 实验 041 补充：三组训练种子的配对复验

## 为什么复验

实验 041 单次训练中，正负交替组成功 `4/20`，只训练正方向组 `0/20`；轨迹显示均衡组仍有明显失败。为了检查改善是否完全依赖一次初始化，预先固定三个训练种子 `26、126、226`，每个种子都按同一实验 041 协议训练两组，比较**配对差异**。评价换用新的任务 seed `300026–300045`，没有根据结果换任务或挑最好模型。

两组在每个种子下仍有相同初始网络权重、`1,200` 仿真交互步、`1,136` 次更新和 `12` 个完整训练回合；目标距离序列相同，仅目标方向安排不同。正方向单一组采集 `1200/0` 条正/负目标转移，均衡组采集 `600/600`。P 控制器在同一批评价任务上只运行一次。配置见 [`configs/041_sac_direction_multiseed.json`](../../configs/041_sac_direction_multiseed.json)；训练、评价和检查继续复用实验 041 代码。

运行：

```bash
conda activate robot_learning
cd ~/AI_Project/robot-learning
PYTHONPATH=src python experiments/041_sac_direction_coverage/run_multiseed.py
```

忽略 Git 的 [`multiseed_results.json`](../../outputs/041_sac_direction_coverage/multiseed_results.json) 保存所有种子的训练计数与评价汇总，[`multiseed_episodes.csv`](../../outputs/041_sac_direction_coverage/multiseed_episodes.csv) 保存逐任务记录。脚本验证配对模型看到相同的目标，且 P 控制器看到同一批任务；评价集共 `8` 个正目标、`12` 个负目标。

## 结果

| 训练种子 | 只训练正方向：正/负成功 | 正负交替：正/负成功 | 两组总成功 |
| ---: | ---: | ---: | ---: |
| 26 | 0/8、0/12 | 0/8、6/12 | 0/20 → 6/20 |
| 126 | 0/8、0/12 | 2/8、4/12 | 0/20 → 6/20 |
| 226 | 0/8、0/12 | 2/8、1/12 | 0/20 → 3/20 |

固定 P 控制器在这批任务上成功 `2/20`，仅作同环境参照。三次配对中，正负交替组成功数都高于只训练正方向组，但分别为 `6、6、3`，且成功方向不同；不能只选种子 26 或 126 宣称双向稳定。三个模型重复接受**同一批 20 个任务**，不是 60 个互不相关的新任务，也不能据此作强统计推断。

尤其要区分成功判据：种子 226 的均衡模型平均最终距离约 `0.073 m`，但仅成功 `3/20`。其中 5 条失败在最后一步已经进入 `0.05 m` 位置容差，终点速度仍高于 `0.10 m/s`；位置接近不等于满足闭环成功。这也说明实验 041 原种子的“所有失败都没走到附近”不能推广到新种子。

## 结论与限制

在这个小预算、三训练种子、固定任务的仿真协议下，方向覆盖带来的成功数提升不是只出现一次；但 SAC 仍没有稳定完成双向目标，结果随初始化和训练轨迹变化。这里检验的是**这一份实现与训练协议**，不是 SAC 一般性能。下一步若继续，宜先把任务完成条件中的“到位”和“低速”分别诊断，再决定要不要增加预算或调整训练协议；任何变化都需要独立评价，不能把旧结果与新协议直接拼接。

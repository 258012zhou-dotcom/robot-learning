# 实验 030：MDP 与折扣回报

## 目标

在训练强化学习策略之前，先验证 MDP 的组成和折扣回报计算。实验分为两个部分：

1. 用一个透明的两步 MDP 比较“立即获得 1”和“晚一步获得 2”。
2. 对现有点机器人一条完整轨迹计算不同 `γ` 下的回报。

## 核心概念

MDP 写作 `(S, A, P, R, γ)`：状态、动作、状态转移、即时奖励和折扣因子。策略 `π(a|s)` 根据状态选择动作。

从时刻 `t` 开始的回报为：

```text
G_t = r_t + γr_(t+1) + γ²r_(t+2) + ...
```

也可以从 Episode 末尾向前递推：

```text
G_t = r_t + γG_(t+1)
```

`γ=0` 只考虑眼前奖励，`γ=1` 在有限 Episode 中不衰减未来奖励。`γ` 是任务定义的一部分，不能在不同 `γ` 的数值之间直接判断哪个策略更好。

## 当前点机器人的对应关系

| MDP 部分 | 当前环境中的内容 |
| --- | --- |
| 状态/观察 | 位置、速度、目标位置、目标误差 |
| 动作 | 一个有界电机命令 |
| 转移 | 一个控制周期内的 MuJoCo 物理步进 |
| 奖励 | 负目标距离减去动作惩罚 |
| 策略 | 本实验用 P 控制器生成一条轨迹 |
| Episode 结束 | 成功到达，或达到最大步数 |

严格说，环境内部完整物理状态是 State，策略接收到的是 Observation。当前观察包含完成一维到达任务所需的主要信息，所以先用它建立 MDP 直觉；以后遇到相机图像、遮挡或延迟时要进一步区分 POMDP。

# 实验反思

## 实验问题

强化学习优化的是长期回报，而不是孤立的一步奖励。实验先使用透明奖励序列检查折扣的含义，再映射到真实仿真轨迹，避免直接训练 PPO 后才猜测数字代表什么。

## 结果

在奖励序列 `quick=[1]`、`patient=[0, 2]` 中，两个选择的初始回报分别是 `1` 和 `2γ`。因此 `γ<0.5` 时立即奖励更高，`γ=0.5` 时打平，`γ>0.5` 时延迟奖励更高。这个结果直接展示了折扣因子如何改变长期与短期奖励的权衡。

点机器人固定目标 Episode 在 242 步成功，普通累计奖励为 `-97.509`。计算得到 `γ=1` 时 `G_0=-97.509`，并且所有时刻都满足 `G_t = r_t + γG_(t+1)`。这验证了实现，但还没有训练任何强化学习策略。

## 易错点

- Reward 是单步反馈，Return 是从当前时刻开始的累计折扣奖励，二者不是同一个量。
- 当前机器人奖励是负成本，所以更接近 0 通常更好；但不能跨不同 `γ` 直接比较回报数值。
- `γ` 不只是计算技巧，它会改变智能体优化的目标。
- 策略看到的是 Observation，不一定等于环境完整 State。当前先按近似完全可观测任务理解；相机遮挡、历史依赖或延迟会引出 POMDP。

## 当前边界

本实验只计算给定策略和给定轨迹的回报，没有学习策略，也没有估计价值函数。它是进入 Value、Q 和 Advantage 前的基础，不是强化学习算法结果。

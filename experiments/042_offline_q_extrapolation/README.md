# 实验 042：固定数据中的 Q 值外推风险

## 先理解问题

离策略（off-policy）允许用旧数据更新策略；离线强化学习（offline RL）进一步要求**训练期间数据集固定、不能再向环境采样**。实验 033 中，在线探索能试出没见过的动作；如果训练只能使用固定数据，这条纠错途径就没有了。

本实验只用两条转移，观察一个具体机制，不实现完整的离线 RL 算法：

```text
固定数据：S0 --动作0, 奖励0--> S1 --动作0, 奖励1--> 终止
未采到：S1 --动作1--> ?
```

令 `γ=0.9`，动作 1 从未被采到，但演示用的 Q 表给它一个任意偏高的初值 `Q(S1,动作1)=5`。先用已知终止转移得到 `Q(S1,动作0)=1`。普通 Q-Learning 计算 `S0` 的目标时，对 `S1` 的**所有**动作取最大值：`0 + 0.9 × max(1, 5) = 4.5`。若只把数据中出现过的动作 0 当作参考，目标则是 `0 + 0.9 × 1 = 0.9`。

这不是说后者一定是真实最优值。假设 `S1` 的未见动作也会立即终止，完全相同的固定数据同时兼容两种世界：未见动作真实奖励为 `0` 时，`S0` 最优回报是 `0.9`；若真实奖励为 `10`，最优回报是 `9.0`。训练数据本身无法区分。`Q=5` 是人为设定的未验证估值，用来展示 TD 外推链条；不声称实际离线 RL 总会出现这个数值或总会高估。

## 运行与检查

```bash
conda activate robot_learning
PYTHONPATH=src python experiments/042_offline_q_extrapolation/run.py
```

程序复用已测试的 `update_q_table`，先确认未见动作的 Q 值没有被数据更新，再核对它进入普通 `max Q` 目标。结果写入被 Git 忽略的 `outputs/042_offline_q_extrapolation/results.json`。配置见 `configs/042_offline_q_extrapolation.json`。

实际运行结果：未见动作的 Q 值保持 `5→5`；普通目标为 `4.5`，仅参考已见动作的目标为 `0.9`。两种假设世界下的真实最优回报分别为 `0.9` 和 `9.0`，但它们对应完全相同的训练数据。相关 Q-Learning 与 TD 单元测试运行 `11 passed`；这只验证计算和本次演示，不是离线策略的闭环评价。

## 结论边界

这个两状态表格例子只验证：**固定数据不能证实未见动作的价值，普通 bootstrapping 可以把该估计传到已见动作。** “只参考已见动作”是帮助理解数据支持范围的对照，不是完整离线 RL 方法，也不保证能找到数据外更好的动作。本实验没有神经网络、连续动作、真实机器人或论文复现结果。

# 实验 042 反思

本实验把“用了旧数据”与“完全不能采集新数据”分开了。固定数据没有 `S1,动作1`，因此它的 `Q=5` 只是未经检验的假设；普通最大值目标会把它传给 `S0,动作0`。即使只在已见动作上取最大值能避开这次人为高估，也可能错过数据外真正更好的动作。下一步学习离线 RL 时，应先问数据覆盖了哪些状态和动作，再谈 Q 值、策略提升或闭环成功。

本次运行的 `4.5` 对 `0.9` 是由选定的初值 `5`、折扣 `0.9` 和两条固定转移算出来的，不是从真实机器人或新环境交互中测到的效果。两种假设世界都与数据一致，进一步提醒我：离线训练损失或 Q 值大小不能单独证明未见动作好坏。

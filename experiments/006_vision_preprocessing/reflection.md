# 实验反思

## 实际结果

- 视觉预处理单元测试：13 个全部通过。
- 全项目回归测试：125 个全部通过。
- 原始图像形状：`(480, 640, 3)`。
- 原始目标框：`(400, 120, 120, 160)`。
- Letterbox 后目标框：`(140, 70, 42, 56)`。
- 相机焦距从 `600` 缩放为 `210`，主点变为约 `(111.825, 111.825)`。
- 模型输入为 RGB、`float32`、`NCHW=(1, 3, 224, 224)`，数值范围为 `[0, 1]`。
- 在本机运行时，模型张量成功移动到 `cuda:0`。

## 人工检查

- Mask 只保留一大一小两个绿色区域，没有包含红色干扰物。
- 程序按面积选择主要绿色目标，黄色框位置正确。
- Letterbox 保持了目标和圆形的比例，并在图像上下补边。
- 模型输入坐标系中的黄色框与变换后的目标一致。

## 结论

视觉流水线不能只改变图像本身。Resize 和 Padding 之后，目标框与相机内参必须执行相同的几何变换，否则模型输出、像素坐标和三维投影将无法对应。

OpenCV 图像与 PyTorch 模型的默认契约不同。本实验明确完成了 BGR/HWC/`uint8` 到 RGB/NCHW/`float32` 的转换，并加入 Batch 维和设备迁移。

## 局限与下一步

- 输入是合成图像，不包含光照变化、遮挡、运动模糊和传感器噪声。
- HSV 颜色范围只能作为可解释基线，无法替代学习型目标检测器。
- 当前只处理一个最大目标，没有类别、置信度和多目标结果。
- 下一步学习 CNN，并用学习型图像分类实验验证特征提取和训练流程。

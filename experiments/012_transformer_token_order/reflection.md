# 实验反思

## 待验证问题

- 无位置模型是否稳定停留在 50% 左右？
- 位置模型是否能学习 Token A 与 B 的先后关系？
- 同一成对样本在无位置模型中是否得到相同概率？
- 位置模型是否在未见过的 filler Token 组合上泛化？

## 解释原则

- 如果无位置模型超过 50%，首先检查数据是否严格成对、是否存在泄漏或其他顺序线索。
- 如果位置模型失败，检查优化、数据规模和池化方式，不能据此否定位置编码原理。
- 实验只比较是否有位置编码，不同时改变模型宽度、层数或训练数据。

## 实际结果

- 无位置模型测试损失为 `0.6932`，准确率为 `50.00%`。
- 位置模型测试损失为 `0.0004`，准确率为 `100.00%`。
- 无位置模型对第一组成对排列输出完全相同的正类概率 `0.4926869`。
- 位置模型对正序和逆序分别输出 `0.9997968` 和 `0.0002189`。
- 无位置模型训练曲线始终处于随机猜测水平；位置模型约在第 7 轮后快速学习，并在第 11 轮达到满分验证准确率。

## 现象解释

每个正负样本包含完全相同的 Token，只交换 A 与 B。没有位置编码时，Token Embedding、Self-Attention 和逐 Token MLP 都只根据内容工作；最终平均池化又消除了排列，因此同一对样本的序列级表示和 logits 必然相同。

交叉熵 `ln(2)≈0.6931` 是二分类模型为两个类别各分配约 50% 概率时的典型损失。无位置模型稳定停在该值，符合结构上的不可辨识性，而不是普通欠拟合。

可学习位置向量让相同 Token 在不同位置具有不同输入表示。模型因此可以学习 A、B 的位置关系，并泛化到独立测试集中未见过的 filler Token 组合。

## 限制与下一步

- 任务只有两个特殊 Token 和固定长度序列，远比自然语言简单。
- 使用绝对可学习位置编码，没有比较正弦编码、RoPE 或相对位置偏置。
- 使用平均池化，没有比较 CLS Token 或自回归解码。
- 没有 Padding Mask、变长序列或 Causal 语言生成任务。

下一步学习预训练与微调，再把视觉表示、文本 Token 和下游任务连接起来。

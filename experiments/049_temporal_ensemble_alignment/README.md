# 实验 049：重叠动作片段的时间对齐

## 目标与原理

三个长度为 3 的片段分别在绝对时间 `0、1、2` 生成。本实验只计算绝对时间 `2` 应执行的动作：从三个片段各取对应的第 `2、1、0` 个位置，不把相邻时间的动作混入。ACT 论文使用同一时刻各预测的加权平均；此处按论文描述将**最早**的有效片段排在 `i=0`，未归一化权重为 `exp(−decay × i)`，最后除以权重和。

这只是对时间索引和权重的教学检查，数值为人工设置；不训练模型、不运行仿真环境，也不证明动作平滑或任务成功率提升。

## 验证方式

单元测试检查绝对时间对齐、等权和指数权重手算、过期片段排除、未来片段拒绝，以及相反预测平均为零的反例。运行入口记录所有参与的片段、偏移、归一化权重与合成动作。

## 实际结果与边界

2026-09-27 实际运行：目标绝对时间是 `2`，衰减系数为 `ln(2)`。只有下列三个位置参与计算，配置中故意放入的 `100、101、200、201、300、301` 等错位值均未混入：

| 片段生成时刻 | 片段内位置（从 0 数） | 对时刻 2 的预测 | 归一化权重 |
| ---: | ---: | ---: | ---: |
| 0 | 2 | 0.3 | 4/7 |
| 1 | 1 | 0.5 | 2/7 |
| 2 | 0 | 0.7 | 1/7 |

手算 `(0.3×4 + 0.5×2 + 0.7×1) / 7 = 0.4142857`，程序输出 `0.4142857`。等权时输出 `0.5`；单元测试也验证 `+0.8` 与 `−0.8` 等权可抵消成 `0`，但**零不因此成为有效动作**。

调用方须按 Episode 隔离片段，不能把上一条轨迹的预测留到下一条轨迹。本次只验证时间对齐与数学合成，没有训练模型、接入环境或证明平滑/成功率收益。旧预测在当前正衰减设置中权重更大；这也可能拖慢对新观察的响应，不能无条件认为越平滑越好。

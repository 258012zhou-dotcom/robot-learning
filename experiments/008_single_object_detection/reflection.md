# 实验反思

## 实际结果

- RTX 5060 Laptop GPU 上使用 `cuda:0` 完成训练。
- 测试集分类准确率为 100.00%。
- 测试集平均 IoU 为 0.8704。
- 以“类别正确且 IoU 不低于 0.5”为标准，检测成功率为 99.00%。
- 不读取图像的平均框基线只有 2.00% 检测成功率，说明 CNN 确实利用了图像中的类别和空间信息。

## 结果解释

分类准确率和平均 IoU 分别回答“是什么”和“在哪里”，联合成功率同时约束两个任务。可视化中的绿色真值框与洋红预测框大多重合，与数值结果一致。

同一配置在执行器 CPU 上得到平均 IoU 0.8694，GPU 为 0.8704。两者结论一致，但浮点实现和硬件执行顺序会带来小幅数值差异，固定随机种子不保证跨硬件逐位相同。

## 限制

- 每张图只有一个目标，不需要预测 objectness 或处理多个候选框。
- 训练、验证和测试都来自同一个合成数据生成器，任务远比真实机器人视觉简单。
- 当前高分不能证明模型能处理遮挡、真实背景、不同相机、旋转目标或多目标场景。
- 虽然已经实现置信度过滤和类别感知 NMS，但本实验每张图只输出一个框，因此没有在训练模型输出上实际使用 NMS。

## 下一步

进入图像分割基础。多目标检测、真实数据集和 mAP 评价留到后续视觉项目需要时深化，不在当前阶段过度扩张。

完成测试和实验运行后，再记录基线、模型结果、可视化现象、限制与下一步。未运行前不填写结论。

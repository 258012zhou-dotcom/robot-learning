# 实验反思

## 实验问题

TD 为什么叫 Bootstrapping？本实验检查当前状态如何使用下一状态尚未完全准确的价值估计进行更新，并与使用完整 Return 的 Monte Carlo 对照。

## 结果

真实价值为 `V(S0)=0.9`、`V(S1)=1.0`。第一次在线 TD 更新 S0 时，下一状态估计仍为 0，所以 `V(S0)` 保持 0；同一 Episode 到达终止奖励后，`V(S1)` 更新为 0.2。从第二个 Episode 开始，S1 已学到的部分价值通过 TD target 逐步传播到 S0。

25 个 Episode 后，TD 估计为 `(0.875, 0.996)`，Monte Carlo 为 `(0.897, 0.996)`；50 个 Episode 后两者显示到三位小数均为真实值 `(0.900, 1.000)`。

终止转移测试还确认：即使错误传入很大的 `next_value`，`terminated=True` 时 TD target 仍只等于终止奖励，不进行 Bootstrapping。

## 结论

Bootstrapping 不是提前知道未来，而是用当前的下一状态价值估计构造学习目标。因此它能在 Episode 结束前更新，但也可能传播错误估计。本实验中 Monte Carlo 更快只是因为轨迹短、确定且完整 Return 没有方差；一般任务仍需根据更新时效、方差和估计偏差选择方法。

## 当前边界

该环境确定、规模极小，Monte Carlo 每次都获得完全相同的 Return。真实机器人中的随机性、函数逼近和数据分布变化都尚未包含，不能根据本实验给两种方法做普遍优劣排序。

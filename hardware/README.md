# 具体设备参考资料

按设备建立子目录，保存型号、软件环境、操作入口、已验证事实和已知问题。用途是让未来部署时能快速了解设备、复用工具、减少重复调试；这里是部署准备资料，不是必须完成的课程。

当前主线是仿真实验与论文复现。本目录不作为仿真成果的验收前置，不默认安排 PIPER 或其他真机部署；以后用户明确提出设备任务时再使用。

- [AGILEX PIPER](piper/README.md)：原 024、025 的记录和工具，以及原 026 的诊断结论。

未来使用其他机械臂、机械狗或传感器时，再按实际设备增加目录，不提前安排实验。通用源码和测试仍放在根目录 `src/robot_learning/`、`tests/`。

历史编号 024–026 不复用；027、028 原为未开展的预留计划，现撤销。历史输出不删除、不重新标记为新验证。

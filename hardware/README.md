# 具体设备参考资料

按设备建立子目录，汇总型号、历史环境、接口单位、已验证事实和已知问题。用途是让未来部署时能快速了解设备、减少重复排查；这里只保留速查总结，不保存历史教学实验或控制脚本。

当前主线是仿真实验与论文复现。本目录不作为仿真成果的验收前置，不默认安排 PIPER 或其他真机部署；以后用户明确提出设备任务时再使用。

- [AGILEX PIPER](piper/README.md)：原 024–026 的有效结论汇总和未来部署检查顺序。

未来使用其他机械臂、机械狗或传感器时，再按实际设备增加目录，不提前安排实验。通用源码和测试仍放在根目录 `src/robot_learning/`、`tests/`。

历史编号 024–026 不复用。删除实验文件不改变当时验证范围；更详细历史仍可从 Git 记录恢复。

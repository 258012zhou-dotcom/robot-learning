# 论文精读与独立复现提示词

本目录保存交给“另一个 Codex 窗口”执行的两类任务：推荐论文的精读提示词，以及独立论文复现型仿真实验提示词。当前项目中的正常概念讲解、基础练习和常规实验不放到这里，仍由当前 Codex 在本项目中带领完成。

当学习进度到达合适节点时，当前 Codex 先说明为什么推荐某篇论文、它与当前知识的关系和本次阅读重点，然后新增一份可独立使用的精读提示词。如果值得进一步复现，再单独提供包含复现范围、仿真配置、基线和验收条件的复现提示词。

使用方式：打开对应文件，复制从“提示词开始”到“提示词结束”的内容，作为新 Codex 任务的第一条消息。论文阅读笔记或复现结果应带回本项目整理和验收。

目前尚未安排外部论文精读或独立复现。提示词不是完成证据；阅读结论需要基于论文原文，复现结论需要基于实际运行的测试、训练和闭环评价。

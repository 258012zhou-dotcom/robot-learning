# 仿真实验与论文复现总结

阶段 4 第一轮之后、进入阶段 5 之前，学习中心放在仿真。用户计划在独立项目中开展几个仿真实验或论文复现，通过实际工作学习软件流程与框架。具体任务、仿真平台、论文、数量和顺序暂未确定，之后由用户提供；SmolVLA 曾被考虑，目前不设为已确定任务。

本仓库只在用户提供结果后整理总结，不提前建立实验、安排训练或部署任务，也不复制外部项目的大型数据和权重。沿用本目录归纳外部仿真实验及论文复现，避免拆分重复入口。目前没有已完成的外部仿真实验或论文复现总结；已有 017–023 的基础仿真实验记录仍保留原位。

每篇总结按实际内容组织，建议涵盖：

- 论文与外部项目入口、代码版本、复现目标和实际覆盖范围。
- 方法理解：输入输出、模型和数据流程，以及关键设计解决的问题。
- 环境、数据划分、配置、评价协议和可重跑的结果来源。
- 仿真器与任务版本、机器人模型、观察与动作定义、控制频率、初始条件、随机种子及评价回合数。
- 仿真中的基线对照、任务成功率、失败类型；有性能结论时记录测量硬件和计时口径。
- 原论文与本次结果的比较；任务或协议不同时说明不可直接比较。
- 失败与负结果、原因分析、流程经验、仍不理解的内容。

区分跑通推理、微调成功、完成评价与复现论文结论，不因 loss 下降或程序运行成功宣称复现完成。总结后再将真正形成体系的知识补入概念笔记；阶段 5 是否启动由用户另行决定。

仿真闭环结果是当前有效的学习成果，不要求补做 PIPER 实验或真机部署才算完成。若只复现论文的仿真部分，明确范围，不声称复现真机结论或全部论文结果。

# 视觉表示学习

## 快速复习

视觉表示学习（Visual Representation Learning）把图像转换为可比较、可复用的特征：

```text
image → encoder → embedding / feature map / visual tokens
```

一个有用表示需要同时满足：

- 保留任务需要的信息，例如形状、位置、姿态和物体身份。
- 对任务无关变化适度稳定，例如亮度、颜色噪声或轻微视角变化。
- 不把所有输入映射成几乎相同的向量。
- 能在未参与训练的下游数据上被简单方法利用。

训练损失下降不是充分证据。需要结合冻结特征评价、不变性、特征变化和下游任务结果。

## 表示的三种常见形态

- Global Embedding `(N,D)`：每张图一个向量，适合分类、检索和全局状态。
- Spatial Feature Map `(N,C,H',W')`：保留空间布局，适合检测、分割和控制中的局部对应。
- Visual Tokens `(N,L,D)`：把图像区域表示为 Token 序列，便于送入 Transformer 和多模态模型。

全局向量压缩程度最高，但可能丢失“目标在哪里”。具身任务经常同时需要语义和空间信息，因此不能把所有视觉问题都简化为单个向量。

## Encoder 与任务 Head

编码器提取可复用特征，Head 把特征映射到具体任务输出：

```text
image → encoder → representation → classification head
                                └→ detection head
                                └→ policy / action head
```

监督训练时，分类损失会通过 Head 反向传播到编码器。训练后移除分类 Head，再用冻结编码器评价，可以更直接地观察表示是否可复用，而不是只评价原分类器。

## 归一化与余弦相似度

对向量做 L2 归一化：

```text
z_normalized = z / ||z||₂
```

归一化后，两个向量点积就是余弦相似度：

```text
similarity(zᵢ, zⱼ) = zᵢᵀ zⱼ
```

它主要比较方向，不让向量长度主导结果。相似度接近 1 表示方向接近，接近 0 表示近似正交，接近 -1 表示方向相反。

高相似度不一定是好事。如果所有图像的特征都接近同一方向，任意两张图都会显得相似，但表示几乎没有区分信息。

## 对比学习

实例对比学习先为每张图生成两个视图：

```text
image i → augmentation A → view i,a → encoder → z i,a
        └→ augmentation B → view i,b → encoder → z i,b
```

来自同一原图的两个表示是正样本对（Positive Pair）；批次中的其他图像通常作为负样本（Negative Samples）。NT-Xent 损失鼓励正样本相似度高，同时压低相对负样本相似度。

温度参数 `temperature` 控制 softmax 对相似度差异的敏感程度：温度较低会更强调最相似的样本，但过低可能导致优化不稳定。

增强策略实际定义了模型应该忽略什么：

- 颜色和亮度增强：希望表示减少对外观强度的依赖。
- 随机裁剪：希望局部视图仍保留物体语义，但可能破坏位置任务。
- 旋转增强：适合旋转不影响类别的任务，不适合方向本身决定动作的任务。
- 模糊和噪声：提高对成像质量变化的容忍度，但过强会删除有效信息。

具身任务中，增强必须服从控制语义。若左右翻转图像却不同时变换动作标签，模型可能学到错误的视觉—动作对应。

## False Negative 与表示坍塌

实例对比学习通常把不同图片视为负样本，即使它们属于同一语义类别。这类 false negative 会迫使同类实例分开，可能不利于类别聚类。大批次、样本选择、监督对比学习或其他自监督目标可以改变这一问题，但各有代价。

表示坍塌（Representation Collapse）是指许多输入得到相同或高度相似的表示。常见诊断包括：

- 各维度标准差过小。
- 不同样本平均余弦相似度接近 1。
- 下游 1-NN、Linear Probe 或检索性能接近无信息基线。

单独使用“同一图像增强前后相似度”会误判：完全坍塌的模型也具有完美不变性。

## 表示评价

常见冻结评价方法：

- k-NN：在特征空间寻找最近样本，不训练新模型。
- Linear Probe：冻结编码器，只训练线性分类层。
- Retrieval：观察同类、同任务或同状态样本是否被检索出来。
- 下游迁移：把表示用于检测、策略学习或状态估计，这是更接近最终目标的证据。

评价时必须分离训练集和测试集。参考库可以来自训练集，但测试查询不能参与编码器训练或超参数选择。

二维 PCA/SVD 图只能展示特征的一部分投影。类别看起来重叠不代表高维空间一定不可分，类别分开也不等于真实数据泛化良好，因此需要与定量指标共同解释。

## 项目证据

实验 011 使用相同结构和初始权重比较三种编码器，并统一采用冻结特征余弦 1-NN：

- 未训练：clean `63.33%`，appearance challenge `52.78%`。
- 监督训练：clean `100.00%`，appearance challenge `63.33%`。
- 对比训练：clean `100.00%`，appearance challenge `73.33%`。

对比增强只改变颜色增益和噪声。对比表示在强外观扰动上的结果比监督表示高 10 个百分点，说明训练目标确实提高了针对这些变化的不变性。

未训练表示的 clean/challenge 相似度为 `0.9990`，但特征维度标准差仅 `0.0065`、不同样本平均余弦相似度为 `0.9978`。这是“高不变性但低信息量”的反例，证明必须联合观察多个指标。

当前证据来自两类合成形状，不足以证明模型具备真实机器人视觉迁移能力。后续需要真实图像、更多类别、视角和遮挡变化，以及检测、策略或视觉语言任务中的下游评价。

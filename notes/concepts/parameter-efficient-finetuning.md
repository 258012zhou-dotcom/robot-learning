# 参数高效微调与 LoRA

## 快速复习

- PEFT（Parameter-Efficient Fine-Tuning）冻结大部分预训练参数，只训练少量新增或选定参数。
- Linear Probe 只训练任务头；Adapter 插入瓶颈模块；Prompt Tuning 学习软提示；LoRA 学习低秩权重增量。
- LoRA 不直接修改基础权重，而是学习 \(\Delta W=(\alpha/r)BA\)。
- Rank 控制适配容量，Alpha 控制更新缩放；参数少不代表任何任务都能适配。
- LoRA 目标模块必须真正参与框架前向，不能只根据名称判断注入成功。
- 适配后可只保存 LoRA 参数，也可把增量合并回普通线性层用于推理。

## 为什么需要 PEFT

完整微调需要为全部参数保存梯度和优化器状态，并为每个任务保存一份完整权重。PEFT 主要降低可训练参数、优化器状态和任务检查点大小，适合大模型、多任务和小数据适配。

PEFT 不一定按同样比例降低所有显存：冻结模型仍需前向计算，激活值和输入长度也会占用显存。量化负责降低参数存储精度；QLoRA 是量化基础模型与 LoRA 的组合。

## LoRA 数学结构

原线性层为：

\[
y=Wx+b
\]

LoRA 冻结 \(W\) 和 \(b\)，加入：

\[
y=Wx+b+\frac{\alpha}{r}BAx
\]

若 \(W\) 形状为 \(d_{out}\times d_{in}\)，则：

- \(A\) 形状为 \(r\times d_{in}\)
- \(B\) 形状为 \(d_{out}\times r\)
- 新增参数量为 \(r(d_{in}+d_{out})\)

实验实现将 A 随机初始化、B 初始化为零，因此开始时 \(BA=0\)，注入前后输出一致。第一次反向传播时 B 先获得非零梯度；B 离开零值后，A 才得到有效非零梯度。

## Rank、Alpha 与 Dropout

- Rank 较小：参数少，但适配容量可能不足。
- Rank 较大：容量提高，同时增加存储、过拟合风险和优化成本。
- Alpha 通常通过 \(\alpha/r\) 形成缩放，避免改变 Rank 时更新幅度完全失控。
- LoRA Dropout 只作用于训练增量分支，评估与权重合并时关闭。

Rank 不是越大越好，应结合目标任务验证集、来源能力保持率和多随机种子波动选择。

## 注入目标模块

Transformer 常见候选包括 Attention 的 Q/K/V/输出投影和 MLP 线性层。目标位置决定 LoRA 能调整什么能力：

- 语言表达变化可优先尝试文本侧 Attention 或 MLP。
- 视觉域变化需要视觉编码器中的适当层。
- 跨模态关系变化可能需要投影层或融合层。

实验 015 只向文本 Transformer 的 `linear1`、`linear2` 注入 Rank 4 LoRA。基础模型有 34,784 个参数，LoRA 训练 768 个参数；加入 LoRA 后的可训练比例约为 2.16%。

## 框架兼容性

只替换一个名为 `linear1` 的模块，不保证 LoRA 已生效。PyTorch Transformer 在某些评估快速路径中会直接读取 `.weight` 和 `.bias`。如果包装器只实现 `forward()`，可能出现报错或增量被绕过。

当前项目通过以下证据验证注入：

- 真实 VLM 注入前后的初始向量一致。
- 把 LoRA B 改为非零后，VLM 文本向量确实改变。
- 只有 A/B 参数可训练并获得梯度。
- 合并前后推理输出一致。
- 无效模块名在任何修改发生前被拒绝。

## 保存与合并

多任务部署时通常保存：

```text
共享基础模型 + 每个任务的小型 LoRA Adapter
```

单任务推理时可以计算：

\[
W_{merged}=W+\frac{\alpha}{r}BA
\]

合并后恢复为普通线性层，不再增加额外分支。合并适合推理，但会失去运行时自由切换 Adapter 的便利。

## 实验 015 的项目证据

基础模型学习 `a red square` 等规范描述，目标任务使用 `crimson box`、`emerald disk` 等未训练别名。每次目标适配只有 30 对图文，共重复三次。

- Frozen：目标 `16.67%`，来源 `100.00%`。
- LoRA：目标 `100.00% ± 0.00%`，来源准确率 `100.00% ± 0.00%`。
- Full Fine-tuning：目标 `99.81% ± 0.26%`，来源 `94.81% ± 5.06%`。

LoRA 的来源 margin 仍有下降，所以不能声称完全没有表示漂移。该任务只改变语言映射，且注入位置与任务高度匹配；结果证明的是“合适位置的 LoRA 在当前任务上高效”，不是 LoRA 普遍优于完整微调。

## 与具身智能的关系

机器人模型经常需要适配新任务词汇、新场景描述、不同相机或不同机器人。PEFT 允许共享基础模型，为不同机器人或任务保存小型 Adapter。但若适配涉及动作空间、传感器结构或控制频率，单纯文本侧 LoRA 往往不够，必须根据变化来源选择模块并进行安全验证。

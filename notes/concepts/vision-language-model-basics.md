# 视觉语言模型基础

## 快速复习

- VLM（Vision-Language Model）把图像和语言连接起来，但本身不等于输出机器人动作的 VLA。
- 双编码器分别生成图像向量和文本向量，通过余弦相似度完成图文检索和提示词分类。
- 对比学习同时拉近正确图文、推远错误图文；对称损失同时训练 Image→Text 和 Text→Image。
- 共享向量维度只保证接口可比较，真正的语义对齐来自配对数据和训练目标。
- 重复语义若被当成负样本会形成假负样本，需要调整 batch 或使用多正样本损失。
- 在训练概念上使用文本代替分类头，不等于对未见类别具有严格 Zero-shot 能力。

## 从单模态表示到多模态表示

视觉编码器把图像映射为向量：

\[
z_i=f_{\mathrm{image}}(x_i)
\]

文本编码器先把文本分成 Token，再映射为文本向量：

\[
z_t=f_{\mathrm{text}}(t_j)
\]

两个编码器可以有不同内部结构，但最终输出必须具有相同维度。通常再进行 L2 归一化，使点积等价于余弦相似度：

\[
s_{ij}=\frac{z_i^\top z_{t_j}}{\tau}
\]

温度参数 \(\tau\) 控制相似度分布的尖锐程度。较小温度会放大分数差异，也可能使训练更敏感。

## 三类常见 VLM 结构

### 双编码器

图像和文本独立编码，最后比较向量。优点是可以预先缓存特征，适合大规模检索和提示词分类；限制是图文之间缺少细粒度 Token 交互。

### 融合编码器

把视觉 Token 和文本 Token 一起送入 Transformer，通过 Self-Attention 或 Cross-Attention 建立细粒度关系。它更适合关系判断和视觉问答，但每个图文组合通常都要重新计算。

### 生成式 VLM

通常由视觉编码器、投影层和语言模型组成。视觉特征被转换成语言模型可接收的视觉 Token，模型再生成文本答案。生成能力不保证视觉事实正确，仍需警惕幻觉。

## 对称图文对比学习

一个含有 \(N\) 对图文的 batch 会产生 \(N\times N\) 相似度矩阵。正确配对位于对角线。典型损失为：

\[
L=\frac{1}{2}(L_{\mathrm{image\rightarrow text}}+L_{\mathrm{text\rightarrow image}})
\]

两个方向都使用交叉熵：每张图应找到正确文字，每条文字也应找到正确图像。

标准一一配对损失隐含假设：同一个 batch 中只有一个正确配对。如果两张不同图片都描述为 `a red square`，把它们互相视作负样本就不合理。实验 014 每个 batch 从每个概念只取一张图，避免了当前数据中的假负样本。大规模系统可使用多正样本损失、去重或更精细的配对标签。

## Token、Padding 与文本池化

- `<PAD>` 用于把不同长度的文本补齐到同一长度。
- `<UNK>` 表示词表之外的未知词，但大量未知词会损失语义。
- Padding Mask 阻止 Transformer 把补齐位置当成真实内容。
- 文本 Encoder 可以使用 CLS Token、平均池化或其他注意力池化得到整句向量。

实验 014 使用简单英文分词、可学习词嵌入、位置编码、Transformer 和忽略 Padding 的平均池化。它适合教学，不具备真实 Tokenizer 的子词能力。

## 评价方式

- Image→Text Accuracy：图像是否选中正确概念文本。
- Text→Image Accuracy：文本最高分图像是否属于正确概念。
- Similarity Margin：正确文本分数减去最强错误文本分数。正值表示正确概念占优。
- Confusion Matrix：观察错误来自颜色、形状还是其他偏差。
- Recall@K：大规模检索中，正确结果是否出现在前 K 名。

当一个概念对应多张图时，不能强制文本只匹配某一张固定图片。评价必须区分实例级配对和语义级配对。

## 实验 014 的项目证据

实验包含红、绿、蓝三种颜色以及方形、圆形两种形状，共六个概念。训练、验证和测试数据使用不同随机种子生成。

- 未训练双向准确率均为 `16.67%`，平均 margin 为 `-1.4253`。
- 训练后双向准确率均为 `100.00%`，平均 margin 为 `7.3462`。
- 相似度矩阵从无明确结构转为明显对角结构。
- 测试混淆矩阵从单一类别偏置转为完全正确的六类对角矩阵。

这些结果验证了封闭合成分布中的图文对齐机制。由于所有六种概念和规范描述都出现在训练中，它不构成未见类别 Zero-shot、自然语言泛化或真实机器人视觉能力的证据。

## 与具身智能的关系

VLM 可以把机器人图像与语言目标连接起来，例如检索“红色杯子”或判断观测是否符合任务描述。但机器人最终还需要空间定位、状态估计、动作表示、控制、安全限制以及失败恢复。VLM 提供语义，不自动解决闭环控制。

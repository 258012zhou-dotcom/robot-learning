# 语义分割基础

## 快速复习

语义分割为每个像素预测一个类别：

```text
RGB 图像 (N, 3, H, W)
→ Encoder 提取语义特征
→ Decoder 恢复空间分辨率
→ Logits (N, C, H, W)
→ argmax(dim=1)
→ 类别 Mask (N, H, W)
```

训练标签是 `int64` 类别编号，不是用于展示的 RGB 彩色图。评价时不能只看 Pixel Accuracy，还要查看每类 IoU、mIoU 和前景指标。

## 分类、检测与分割

- 图像分类：回答整张图“是什么”。
- 目标检测：回答“是什么、在哪里”，位置通常是矩形框。
- 语义分割：回答每个像素属于哪个语义类别。
- 实例分割：除语义类别外，还区分同类别的不同物体实例。
- 全景分割：统一处理可数实例与道路、天空等不可数区域。

语义分割保留的轮廓比检测框精细，但计算、标注和评价成本也更高。

## 图像与 Mask 数据契约

多类别分割中常见 Tensor 形式：

```text
images: float32, (N, 3, H, W)
logits: float32, (N, C, H, W)
masks:  int64,   (N, H, W)
```

Mask 的每个整数是类别编号。例如：

```text
0 = background
1 = square
2 = circle
```

可视化时可以用调色板把类别编号映射为颜色，但不能把展示颜色直接当作类别标签。使用 Cross Entropy 时，不应先对 logits 执行 Softmax。

几何增强必须同步作用于图像与 Mask，包括裁剪、缩放、旋转、翻转和 Letterbox。Mask 变换通常使用最近邻插值，避免双线性插值产生不存在的中间类别编号。亮度、颜色和噪声等外观增强通常只修改 RGB 图像。

## Encoder、Decoder 与 Skip Connection

编码器通过卷积和下采样扩大感受野、提取语义特征，但空间分辨率逐渐降低。解码器通过上采样恢复输出尺寸。

U-Net 风格的跳跃连接：

```text
浅层高分辨率特征 ─────────────┐
                              ↓ 拼接
Encoder → Bottleneck → Decoder → Pixel Logits
```

深层特征更擅长判断“是什么”，浅层特征保留边缘和位置。跳跃连接把二者结合，有助于恢复目标边界和小结构。

实验 009 使用双线性插值恢复尺寸，再与对应编码器特征拼接。双线性插值没有可学习参数，后续卷积负责融合和修正特征。转置卷积也可用于上采样，但配置不当可能产生棋盘状伪影。

## 像素级交叉熵与类别不平衡

多类别分割可直接使用像素级 Cross Entropy：

```text
L = CrossEntropy(logits, target_mask)
```

一张图中背景常远多于目标。若所有像素权重相同，模型可能优先优化背景。常见方法包括：

- 按类别频率设置权重。
- Cross Entropy 与 Dice Loss 组合。
- Focal Loss 关注困难像素。
- 重采样或裁剪包含前景的区域。

实验 009 根据训练 Mask 的像素频率计算逆频率权重，并把权重归一化为平均值 1。权重只影响训练损失，不应修改测试集上的原始指标统计。

类别权重过大也可能带来前景误报，因此必须同时查看混淆矩阵、背景 IoU 和前景 IoU，而不是默认加权一定更好。

## Pixel Accuracy、IoU 与 Dice

Pixel Accuracy：

```text
预测正确的像素数 / 全部像素数
```

类别 IoU：

```text
IoU_c = 类别 c 的预测与真值交集 / 类别 c 的预测与真值并集
```

Dice：

```text
Dice_c = 2 × 交集 / (预测面积 + 真值面积)
Dice = 2 × IoU / (1 + IoU)
```

mIoU 通常是各类别 IoU 的平均，但必须说明是否包含背景。实验 009 同时报告：

- 三类别 mIoU。
- 只平均正方形和圆形的 Foreground mIoU。

全背景基线在实验中达到 88.65% Pixel Accuracy，但两个前景类别 IoU 都为 0。这说明类别不平衡时，单独的 Pixel Accuracy 可能严重误导。

## 像素混淆矩阵

项目约定：

```text
行 = 真实类别
列 = 预测类别
```

对混淆矩阵按行归一化后，每一行表示该真实类别被预测到各类别的比例。它可以帮助区分：

- 前景被漏成背景。
- 背景被误报为前景。
- 不同前景类别互相混淆。

只查看 mIoU 会丢失这些具体错误方向。

## 具身智能中的使用方式

语义 Mask 常与深度和坐标变换结合：

```text
RGB 分割 Mask
→ 选出目标像素
→ 查询对应深度
→ 使用相机内参反投影
→ 相机坐标系三维点或点云
→ TF2 转换到机器人/世界坐标系
→ 抓取、避障、导航或状态估计
```

实际系统还要检查 RGB 与深度是否时间同步、分辨率和内参是否匹配、Mask 是否存在空洞、目标是否被遮挡，以及推理延迟是否满足控制频率。

## 当前项目证据与知识边界

实验 009 已验证：

- RGB 图像与像素 Mask 的严格对应和可复现生成。
- 小型 U-Net 风格 Encoder–Decoder 与两层 Skip Connection。
- 带类别权重的像素 Cross Entropy。
- 像素混淆矩阵、每类 IoU、mIoU 与 Foreground mIoU。
- RTX 5060 上 Pixel Accuracy 99.93%、mIoU 0.9950、Foreground mIoU 0.9929。

这些结果只证明同分布合成任务闭环正确。前景与背景颜色差异明显，模型可能主要利用亮度线索。尚未验证真实数据、复杂背景、多实例、领域变化、Dice/Focal Loss、现代分割模型或实时部署。

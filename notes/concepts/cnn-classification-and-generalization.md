# CNN 图像分类与泛化

## 快速复习

CNN 使用局部连接和权重共享，从图像中逐层学习空间特征：

```text
RGB NCHW 图像
→ Conv + ReLU
→ 下采样
→ 更深的特征图
→ 全局池化
→ Linear
→ Logits
```

分类训练常用：

```text
CrossEntropyLoss(Logits, int64 标签)
```

训练集用于更新参数，验证集用于选择模型，测试集只用于最终评价。高同分布准确率不等于真实泛化能力，还要检查混淆矩阵、错误样本和合理的分布变化。

## 卷积与特征图

输入通常为 `(N, C_in, H, W)`。`Conv2d` 使用多个可学习卷积核在局部区域滑动，输出：

```text
(N, C_in, H, W)
→ Conv2d
→ (N, C_out, H_out, W_out)
```

输出空间尺寸为：

```text
H_out = floor((H + 2P - K) / S) + 1
```

其中 `K` 是 Kernel Size，`S` 是 Stride，`P` 是 Padding。二维宽度使用同样公式。

卷积参数量为：

```text
C_out × C_in × K_h × K_w + C_out
```

最后一项是每个输出通道的偏置。局部连接让卷积关注邻域，权重共享让同一个特征可以在不同图像位置被检测。

## ReLU、下采样与感受野

ReLU：

```text
ReLU(x) = max(0, x)
```

它为网络加入非线性。没有非线性，多层线性变换仍等价于单个线性变换。

MaxPool 或步长卷积用于降低空间尺寸、减少计算并扩大后续特征的有效感受野。但检测、分割和关键点任务需要精确位置，过早下采样会损失小目标与边界信息。

感受野表示某个深层特征能整合原图多大区域。浅层通常响应边缘和纹理，深层逐渐组合成局部形状和任务相关语义，但具体特征由数据和损失共同决定。

## 全局池化与分类头

`AdaptiveAvgPool2d((1,1))` 把每个通道的空间特征压缩为一个值：

```text
(N, C, H, W) → (N, C, 1, 1) → (N, C)
```

随后 `Linear(C, class_count)` 输出每个类别的 Logit。Logit 是未归一化分数，不等于概率。

`CrossEntropyLoss` 接收：

- Logits：形状 `(N, class_count)`。
- 标签：形状 `(N,)`，类型 `int64`。

训练时不应先手动执行 Softmax，因为交叉熵内部已经使用数值更稳定的 Log-Softmax 关系。推理时可以用 `argmax` 得到预测类别；需要可解释概率时再调用 Softmax。

## 标准训练循环

训练 Batch：

```text
model.train()
→ optimizer.zero_grad()
→ forward
→ loss
→ backward
→ optimizer.step()
```

PyTorch 默认累积梯度，因此每个 Batch 通常要先清理旧梯度。`backward()`计算梯度，`optimizer.step()`才真正修改参数。

验证与测试：

```text
model.eval()
→ torch.no_grad()
→ forward 和指标统计
```

`eval()`切换 Dropout、BatchNorm 等模块的运行模式；`no_grad()`停止记录梯度。两者作用不同，规范评价时通常同时使用。

## 数据划分与模型选择

- 训练集：计算梯度和更新权重。
- 验证集：选择最佳轮次、超参数和模型版本。
- 测试集：方案冻结后做最终评价。

如果反复查看测试集并据此修改数据、模型或超参数，测试集就已经承担验证集作用，不再能提供无偏最终评价。

恢复最低验证损失对应的模型，可以避免直接使用训练最后一轮的退化参数。但验证准确率高仍不能保证分布变化下可靠。

## Accuracy 与混淆矩阵

Accuracy：

```text
正确预测数量 / 总样本数量
```

类别不平衡时必须与多数类基线比较。只看总体 Accuracy 还可能掩盖某一类别完全失效。

混淆矩阵通常约定：

```text
行 = 真实类别
列 = 预测类别
```

对角线是正确预测，非对角线显示具体混淆方向。错误样本可视化用于寻找尺寸、位置、遮挡、背景或分布变化等共同模式。

## IID、OOD 与旋转

IID（Independent and Identically Distributed）测试表示训练与测试来自相近数据生成分布。OOD（Out-of-Distribution）评价则有意改变某个条件，例如角度、光照、背景或传感器。

标准卷积具有一定平移等变性：输入移动时，特征图响应也会移动。池化和全局汇聚可以提供有限的位置鲁棒性，但普通 CNN 不会自然获得任意旋转不变性。

因此：

```text
轴对齐方形训练成功
≠
模型理解了所有角度的方形
```

## 数据增强与领域随机化

数据增强把不应改变标签的变化加入训练分布，例如轻微裁剪、颜色变化或旋转。前提是变化符合任务语义和实际部署条件。

错误增强可能：

- 改变标签含义。
- 产生插值、黑边或裁切伪影。
- 让某种伪影只出现在一个类别中，形成新捷径。
- 过度偏离常规分布，损害 IID 性能。

合成数据中可以直接在渲染阶段随机化位置、角度、材质、光照和相机参数，这通常称为领域随机化。它比事后变换整帧更容易保持几何和标签一致，但仍需验证随机化范围是否合理。

## 受控实验与结论强度

比较增强前后性能时，应尽量保持：

- 模型结构和初始参数一致。
- 样本数量、Epoch、优化器和学习率一致。
- 验证集、测试集和评价代码一致。
- 只改变计划研究的一个因素。

单个随机种子的几个百分点变化只能视为观察。要支持稳定结论，需要多个种子、未参与调试的最终测试集、均值与标准差，必要时使用成对统计比较。

## 当前项目证据

实验 007 已验证：

- RGB NCHW 合成分类数据及可复现划分。
- 三层小型 CNN、CrossEntropyLoss 和 AdamW 训练。
- 最佳验证模型恢复、Accuracy、混淆矩阵和错误样本输出。
- Baseline 在 IID 测试达到 100%，但旋转挑战降至 50%。
- 生成器级旋转随机化基本保留 IID 性能，并观察到小幅 OOD 改善，但没有解决旋转方形失败。

这说明软件流水线和同分布分类任务工作正常，同时也留下明确知识空白：模型的鲁棒性取决于训练分布、架构偏置和评价设计，不能用单一测试准确率代表真实机器人场景能力。

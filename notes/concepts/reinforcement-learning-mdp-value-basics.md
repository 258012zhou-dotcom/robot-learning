# 强化学习：MDP、回报与价值函数基础

## 快速复习

- 强化学习通过环境奖励学习策略，不需要每个状态都有专家动作标签。
- MDP 写作 `(S, A, P, R, γ)`：状态、动作、转移、奖励和折扣因子。
- 马尔可夫性质要求当前状态包含预测下一状态分布所需的信息，不要求环境一定是确定性的。
- Reward 是一步反馈；Return 是从当前时刻开始的累计折扣奖励。
- Policy 决定怎样选动作；`V` 评价状态；`Q` 评价状态下的指定动作；Advantage 表示动作比当前策略平均水平好多少。
- 一次轨迹 Return 只是随机样本，不等于价值期望。Monte Carlo 用多次完整轨迹的样本均值估计价值。

## 1. 强化学习的交互过程

Behavior Cloning 使用专家动作作为监督标签；强化学习通常只从环境获得状态变化和奖励：

```text
状态 s_t
→ 策略选择动作 a_t
→ 环境执行动作
→ 返回奖励 r_t 和下一状态 s_(t+1)
→ 重复
```

智能体的目标不是让某一步 Reward 最大，而是让长期 Return 的期望最大。

## 2. MDP 的组成

```text
MDP = (S, A, P, R, γ)
```

- `S`，State：环境当前处境。
- `A`，Action：智能体可以执行的动作。
- `P`，Transition：当前状态和动作怎样决定下一状态的概率分布。
- `R`，Reward：一步转移产生的反馈。
- `γ`，Discount Factor：未来奖励在当前回报中的权重，范围为 `[0, 1]`。

策略通常写作 `π(a|s)`，表示状态 `s` 下选择动作 `a` 的方式。它可以是确定性的，也可以是一个动作概率分布。

### 马尔可夫性质

给定当前状态和动作后，下一状态的概率分布不再依赖更早的历史。当前状态必须包含足够的信息。

点机器人只有位置时不满足这个要求：相同位置、不同速度的机器人执行同一动作后会到达不同位置。加入速度后，状态才能区分这两种运动趋势。

策略实际接收的是 Observation，不一定等于环境完整 State。当前一维任务的观察包含位置、速度、目标和目标误差，可以先近似按完全可观测 MDP 理解；相机遮挡、动作延迟和历史依赖可能形成 POMDP。

## 3. Reward、Return 与折扣因子

从时刻 `t` 开始的折扣回报为：

```text
G_t = r_t + γr_(t+1) + γ²r_(t+2) + ...
```

也可以从 Episode 末尾向前递推：

```text
G_t = r_t + γG_(t+1)
```

- `γ=0`：只计算当前一步奖励。
- `γ` 接近 1：更多考虑长期结果。
- `γ=1`：有限 Episode 中，Return 等于未折扣累计奖励。

`γ` 会改变优化目标，不只是改变日志显示。它还需要和控制周期一起理解：有效步数可以粗略看作 `1 / (1 - γ)`，有效物理时间还要乘以每个控制步的时间。

实验 030 比较了立即奖励 `[1]` 与延迟奖励 `[0, 2]`：

```text
G_quick = 1
G_patient = 2γ
```

所以 `γ<0.5` 时立即奖励更高，`γ=0.5` 时打平，`γ>0.5` 时延迟奖励更高。

当前点机器人的 Reward 是负距离减去动作成本。更接近 0 的奖励通常更好，但不同 `γ` 定义了不同目标，不能直接跨 `γ` 比较回报数值来判断策略优劣。

## 4. Policy、V、Q 与 Advantage

### Policy

```text
π(a|s)
```

描述状态 `s` 下怎样选择动作 `a`。

### 状态价值 V

```text
V^π(s)
```

表示从状态 `s` 开始，之后一直按照策略 `π` 行动时，未来 Return 的期望。

### 动作价值 Q

```text
Q^π(s,a)
```

表示在状态 `s` 先执行指定动作 `a`，之后再按照策略 `π` 行动时，未来 Return 的期望。

### Advantage

```text
A^π(s,a) = Q^π(s,a) - V^π(s)
```

- `A>0`：动作比当前策略在该状态下的平均水平更好。
- `A<0`：动作比平均水平更差。
- `A≈0`：动作没有明显优劣。

离散随机策略下：

```text
V^π(s) = Σ π(a|s)Q^π(s,a)
Σ π(a|s)A^π(s,a) = 0
```

因此 Advantage 衡量的是相对当前策略的改进方向，而不是绝对回报是否为正。

## 5. Return 样本与 Value 期望

同一个状态多次运行，可能得到不同 Return。一次 `G_t` 只是某一种未来结果；`V` 和 `Q` 是这些可能结果的期望。

Monte Carlo 方法等待 Episode 完成后计算实际 Return，再通过样本平均估计价值：

```text
V(s) ≈ 从状态 s 出发的多个 Return 平均值
Q(s,a) ≈ 在状态 s 先执行 a 后的多个 Return 平均值
```

实验 031 的真实答案为：

```text
Q_safe = 1.0
Q_risky = 1.8
V = 1.2
A_safe = -0.2
A_risky = 0.6
```

但只有 10 次采样时，`Q_risky` 被估计为 0，使真实为正的 Advantage 被错误估计为负。10000 次采样时，`Q_risky` 估计为 1.835，才接近真实值 1.8。

这说明少量样本不仅会带来数值误差，还可能让策略更新方向出错。增加样本通常能降低误差，但随机波动不保证误差随每一次扩充都严格单调下降。

## 6. TD 与 Bootstrapping

Monte Carlo 等待完整 Episode 后使用实际 Return。一步 TD 使用：

```text
TD target = r_t + γV(s_(t+1))
TD error  = TD target - V(s_t)
V(s_t) ← V(s_t) + α × TD error
```

其中 `α` 是学习率。使用下一状态的当前估计来更新当前状态，叫作 Bootstrapping。

如果转移真正终止，未来价值为 0：

```text
TD target = r_t                  if terminated
TD target = r_t + γV(s_(t+1))   otherwise
```

`truncated` 可能只是时间限制，不一定表示任务自然结束，是否继续 Bootstrapping 要根据任务定义处理。

实验 032 的两状态链中，TD 先从终止奖励学到 `V(S1)`，再在后续 Episode 中把价值逐渐传播到 `V(S0)`。Monte Carlo 在这个确定性短链中收敛更快，因为完整 Return 没有随机方差；这不是一般优劣结论。

## 7. 表格型 Q-Learning

Q-Learning 用一步 TD 更新动作价值。下一状态的目标选择当前估计最好的动作：

```text
target = r + γ max_a' Q(s',a')
Q(s,a) ← Q(s,a) + α(target - Q(s,a))
```

真正终止时 `target = r`。训练中可以用 `ε`-greedy：以 `ε` 的概率随机探索，以 `1-ε` 的概率选择当前 Q 最大的动作。实际采样策略包含探索，而更新目标按未来贪心动作计算，因此 Q-Learning 是 Off-policy。

实验 033 中，S0 可以立即拿 1，也可以先到 S1 再拿 2；`γ=0.9` 时后者真实回报为 1.8。零初始化且无探索时，策略始终拿 1；加入 `ε=0.2` 后访问到 S1，最终学到贪心路线回报 1.8。结论只针对这个两状态、固定随机种子的离散任务。

点机器人的动作是连续值，表格型方法无法直接枚举所有动作。本实验用于理解探索和价值传播，后续连续控制要学习策略梯度及 PPO。

## 8. 策略梯度与价值基线

策略梯度直接调整策略参数，让表现比预期好的采样动作以后更可能被选中。一个最小损失是：

```text
policy_loss = -log πθ(a|s) × A(s,a)
A(s,a) ≈ G_t - V(s)
```

负号是因为优化器最小化损失，而目标是最大化回报。`V(s)` 作为基线，提供当前策略的平均水平；减去不依赖所采样动作的基线通常不改变期望策略梯度，但可以降低估计方差。

实验 034 的单状态任务中，低奖励动作得 1，高奖励动作得 2。200 次采样更新后，选高奖励动作的概率从 0.5000 升到 0.9455，精确期望回报从 1.5000 升到 1.9455。初始策略下，使用真实价值基线前后梯度均值均为 0.25；单样本方差从 0.5625 降为 0。这里的零方差是特殊数值设置的结果，真实任务需要估计价值，仍会存在采样噪声。

连续动作策略也能输出动作分布并从中采样，后续再将这一机制连接到点机器人和 PPO。

## 9. Actor-Critic：让基线从数据中学习

实验 034 的真实 `V(s)` 是提前知道的；一般任务中无法直接获得。Actor-Critic 用 Critic 估计当前状态价值，再由 Actor 调整动作概率：

```text
Actor loss  = -log π(a|s) × (实际回报 - Critic(s))
Critic loss = (Critic(s) - 价值学习目标)²
```

Actor 回答“选什么动作”，Critic 回答“当前状态通常能得到多少回报”。更新 Actor 时，把 Critic 的预测当作固定基线，不让 Actor 的损失反向改变 Critic；Critic 则用自己的价值目标更新。本实验只有一步且立即终止，目标就是采样奖励。非终止状态以后可用 `r + γV(s')` 作为一步 TD 目标，但实验 035 尚未验证这部分。

实验 035 的学习型 Critic 组在 200 次更新后，选高奖励动作的概率由 0.5000 升到 0.9437；此时 Critic 预测 1.9781，当前策略的精确价值是 1.9437。第一次采样时，初始 Critic 过低，连低奖励动作都得到正 Advantage，导致高奖励动作概率短暂下降。价值估计有误时，Actor 的单次更新方向也可能不理想。这里只验证了一状态标量 Critic，不能推断多状态任务或 PPO 的效果。

## 10. PPO 裁剪目标：限制旧数据继续推动策略

同一批动作数据来自旧策略。如果用它多次更新 Actor，新策略对这些动作的概率会变化。PPO 的概率比 `ratio = π_new(a|s) / π_old(a|s)` 比较同一状态、同一动作在新旧策略下的概率；`ratio=1` 表示没有变化。

```text
普通目标 = mean(ratio × Advantage)
裁剪目标 = mean(min(ratio × Advantage,
                    clip(ratio, 1-ε, 1+ε) × Advantage))
```

正 Advantage 表示动作更好；若提高它的概率已经使 `ratio>1+ε`，裁剪目标不会继续奖励这种增大。负 Advantage 表示动作较差；若降低它的概率已经使 `ratio<1-ε`，也不会继续奖励这种降低。朝不利方向越界时，目标仍可提供纠正梯度。优化器最小化损失，因此代码把上面的最大化目标取负号。

实验 036 固定旧策略 `P(high)=0.5`、枚举两个动作、使用精确旧 Advantage。更新 40 次后，普通目标的 `P(high)` 为 0.9715，裁剪目标为 0.6216。裁剪组第二次更新就越过 0.6，说明裁剪目标不是概率硬上限。这是机制验证，不是完整 PPO：没有实际 Rollout、学习型 Critic、GAE、重采集或闭环评价。

## 11. PPO 最小闭环：新数据、旧概率与独立评价

实验 036 只有固定数据；真正的 On-policy 训练每轮都要用当前策略重新采集环境轨迹。一次更新的数据流是：

```text
环境轨迹 → 保存旧动作 log-prob、奖励和 Critic 估值
→ 计算 Advantage（实验 037 用 GAE）和价值目标
→ 固定旧 log-prob，重复几轮裁剪 Actor 更新与 Critic 回归
→ 丢弃旧批次，以更新后的策略重新采集
```

真正终止时没有未来价值；时间上限截断不等于自然终止，可用末状态的 Critic 估计 Bootstrapping。训练损失只是优化信号，策略好坏还要在训练外 Episode 上看成功率、回报和失败轨迹。

实验 037 在现有 MuJoCo 一维到达环境中把动作简化为 `-1、0、+1`，完成这一数据流。独立评价 20 个任务中，训练后贪心策略成功 6 个，初始策略 0 个，随机策略 0 个，P 控制器 20 个。训练后策略平均回报还略低于随机策略；正方向目标 0/10 成功，10 条轨迹均越过目标。它是 PPO 学习流程的运行验证和重要负结果，不是稳定策略或论文复现成果。

固定轨迹诊断进一步发现：正目标失败任务第一次进入位置容差时速度仍为 1.128 m/s，动作长期保持 `+1` 后改为 `0` 滑行，首次反向命令直到第 199 步；同目标 P 控制器会逐步减小命令并在第 55 步反向。负目标成功任务则较早反向，近目标速度只有 0.047 m/s。到达成功同时要求位置误差与速度达标，因此最后停在错误位置或高速掠过目标均不算成功。当前训练奖励不直接包含速度项，而成功条件包含速度；这提供一个可检验的奖励设计假设，不是已证实的根因。

实验 038 在相同训练 seed、预算、模型、动作和评价任务下，只给训练奖励加入半径 0.5 m 内的速度惩罚（权重 0.5）；评价仍用原环境奖励。原组逐条复现 6/20 成功，塑形组降为 0/20，平均原环境回报从 -388.11 变成 -519.52。惩罚确实进入训练目标，因此这是具体方案的负结果，不等于“所有速度惩罚都无效”。奖励设计需要受控闭环检验，不能只看公式是否符合直觉。

## 12. 当前已验证与尚未验证

已经实际验证：

- 有限 Episode 的折扣回报及其向后递推。
- `γ` 对立即奖励和延迟奖励权衡的影响。
- `V = ΣπQ`、`A = Q - V` 和策略加权 Advantage 为 0。
- Monte Carlo 状态价值和动作价值估计。
- 少量随机样本可能误判 Advantage 的正负号。
- 一步 TD target、TD Error、学习率更新和终止状态处理。
- Bootstrapping 将下一状态估计逐步向前传播。
- 表格型 Q-Learning 的 `max Q` 更新、探索与独立贪心评价。
- 采样策略梯度更新能提高高回报动作的概率；真实价值基线在小任务中降低单样本梯度方差。
- 一状态、一步终止任务中，学习型 Critic 可从奖励更新价值基线；初始估计误差可能暂时误导 Actor。
- 固定旧策略和精确 Advantage 的两动作任务中，PPO 裁剪目标会停止从旧数据继续奖励有利方向的过大更新，但不是概率硬上限。
- 离散动作 PPO 最小环境循环已运行：多状态神经网络 Critic、GAE、截断 Bootstrapping、重新采样和训练外评价的数据流通过；闭环策略仍明显失败。
- 在固定预算和评价任务下，这次近目标速度奖励塑形使独立成功数由 6/20 降到 0/20；原环境回报也变差。

尚未验证：

- Critic 预测是否准确、不同随机种子下策略是否稳定。
- 连续动作 PPO 与更完整的训练设置。
- 点机器人上达到可靠成功率、并与传统控制基线接近的强化学习策略。

# 网络与 TCP 传感器基础

## 快速复习

TCP 建立的是连续字节流：一次 `send` 不等于对方恰好一次 `recv`。因此应用层必须定义**消息边界**，例如每条 JSON 后加换行符。

```text
客户端 → JSON + "\n" → TCP 字节流 → 服务端
服务端 → JSON + "\n" → TCP 字节流 → 客户端
```

`bind()` 决定服务端监听的地址和端口；`connect()` 连接到该端点；`127.0.0.1` 仅允许当前网络环境访问。

## 项目中的用法

`projects/tcp_sensor_demo/server.py` 监听 `127.0.0.1:50007`，读取一行 JSON 位置样本后返回带相同 `sequence_id` 的确认。客户端使用 `socket.create_connection(..., timeout=2.0)`，避免无限连接等待。

重要限制：本示例只处理一个连接和一条消息；真实机器人系统还需要处理断线、部分读取、消息校验、重连和身份认证。

# 目标检测基础

## 快速复习

目标检测同时回答两个问题：

```text
图像中是什么？→ 类别与置信度
目标在哪里？  → 边界框
```

常见执行流程：

```text
图像
→ Backbone 提取特征
→ 分类、objectness、框回归等预测头
→ 置信度过滤
→ NMS 删除重复框
→ 类别、分数和最终边界框
```

本项目的实验 008 是单目标学习基线：每张图只输出一个类别和一个框，因此能验证分类与定位训练，但还不是完整的多目标检测器。

## 任务层级

- 图像分类（Classification）：整张图输出一个类别，不提供位置。
- 分类加定位（Classification with Localization）：已知只有一个主要目标，同时预测类别和一个框。
- 目标检测（Object Detection）：目标数量未知，需要输出多个类别、分数和框。
- 图像分割（Segmentation）：进一步为像素分配类别或实例。

实验 008 严格来说更接近“单目标分类加定位”，但使用了检测任务相同的框表示、联合损失、IoU 和成功判据，是进入完整检测器的最小闭环。

## 边界框表示与坐标契约

常见边界框格式：

- `xyxy`：`(x_min, y_min, x_max, y_max)`。
- 左上角 `xywh`：`(x_min, y_min, width, height)`。
- 中心点 `cxcywh`：`(center_x, center_y, width, height)`。

框还可能使用像素坐标或相对图像宽高归一化到 `[0,1]` 的坐标。格式和坐标空间必须与图像变换同步记录；Letterbox、裁剪、缩放或翻转后只修改图像而不修改框，会直接制造错误标签。

本项目约定：

- 几何后处理使用连续 `xyxy` 坐标，面积不额外加 1。
- 检测模型回归归一化 `cxcywh`。
- 评价前把 `cxcywh` 转换为裁剪到 `[0,1]` 的 `xyxy`。

## IoU

Intersection over Union 衡量预测框与真值框的重叠：

```text
IoU = 交集面积 / 并集面积
并集面积 = A面积 + B面积 - 交集面积
```

- 完全相同：IoU 为 1。
- 没有重叠：IoU 为 0。
- IoU 越高，定位通常越准确。

IoU 阈值不是自然常数。实验 008 使用 `IoU ≥ 0.5` 作为一次基础成功判据；更严格评价可能同时考察多个阈值。

## 检测器结构

典型检测器可以抽象为：

```text
Backbone → Neck → Detection Head
```

- Backbone：从图像提取视觉特征。
- Neck：融合不同空间尺度的特征，帮助同时处理大小目标。
- Head：预测类别、目标存在概率和边界框。

分类网络常用全局平均池化压缩空间位置。检测需要定位，不能过早彻底丢掉空间布局。实验 008 将特征保留为 `4×4` 后再展平，使回归头能够利用目标位置。

## 分类与框回归联合损失

实验 008 使用：

```text
L_total = L_classification + λ × L_box
```

- `L_classification`：Cross Entropy，学习类别。
- `L_box`：Smooth L1，学习中心、宽度和高度。
- `λ`：平衡两种损失的尺度，实验中为 10。

只看总损失不够。分类损失很低但框损失很高时，模型可能知道“是什么”却不知道“在哪里”；反过来也可能框接近但类别错误。

完整多目标检测还需要解决哪个预测应该匹配哪个真值目标，常见方法涉及 Anchor、Anchor-free、正负样本分配或集合匹配。本实验只有一个目标，因此暂时没有这个问题。

## 置信度过滤与 NMS

多目标检测器通常产生大量候选框：

1. 先删除低置信度候选框。
2. 按置信度从高到低选择框。
3. 删除与已选同类别框高度重叠的低分框。
4. 重复直到没有候选框。

这就是非极大值抑制（Non-Maximum Suppression, NMS）。类别感知 NMS 不会因为两个不同类别的框重叠，就直接互相删除。阈值过低可能误删相邻目标，过高则可能保留重复框。

实验 008 已通过单元测试验证框转换、裁剪、面积、IoU、置信度过滤和类别感知 NMS；由于模型每张图只输出一个框，NMS 尚未进入实际模型推理链。

## 评价指标

本实验使用三组互补指标：

- 分类准确率：类别正确比例，不评价框。
- 平均 IoU：框重叠平均值，不评价类别。
- 检测成功率：类别正确且 IoU 达到阈值的比例。

真实检测任务还常用：

- Precision：预测为目标的结果中有多少是真的。
- Recall：真实目标中有多少被检测出来。
- AP：某一类别在不同置信度阈值下 Precision-Recall 曲线的综合面积。
- mAP：多个类别 AP 的平均，通常还会说明采用哪些 IoU 阈值。

不能只写“mAP”，必须同时说明数据集、类别、IoU 范围和具体计算规范。

## 具身智能中的作用

二维检测框通常只是中间结果：

```text
RGB 检测框
→ 对应深度或点云
→ 相机坐标系中的三维位置
→ TF2 转换到机器人或世界坐标系
→ 路径规划、抓取或控制
```

框中心不一定就是物体可靠三维位置。遮挡、深度空洞、相机标定误差和目标形状都会影响后续定位，因此机器人系统需要保留置信度、坐标系、时间戳和失败处理。

## 当前项目证据与知识边界

实验 008 已验证：

- 可复现的单目标合成数据与归一化框标注。
- 共享 CNN 特征、分类头和框回归头。
- Cross Entropy 与 Smooth L1 联合训练。
- 基线、分类准确率、平均 IoU 和联合成功率评价。
- RTX 5060 上分类 100.00%、平均 IoU 0.8704、检测成功率 99.00%。

这些结果证明最小检测训练闭环有效，不证明已经掌握真实多目标检测。后续知识空白包括多目标匹配、objectness、特征金字塔、真实数据集标注、Precision/Recall/mAP、部署延迟和真实相机域差异。

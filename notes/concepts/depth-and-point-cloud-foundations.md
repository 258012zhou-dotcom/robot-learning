# 深度图与点云基础

## 快速复习

深度图把每个像素与距离连接起来。若深度表示相机光轴方向的 Z-depth，则针孔相机反投影为：

```text
X = (u - cx) × Z / fx
Y = (v - cy) × Z / fy
Z = depth[v, u]
```

在 ROS 相机光学坐标系中通常约定：X 向右、Y 向下、Z 向前。深度值只有结合单位、相机内参、坐标系和时间戳才有意义。

## 深度图的数据契约

RGB 图像保存颜色，深度图的每个像素保存距离或无效标记：

```text
RGB[y, x]   = [R, G, B]
depth[y, x] = depth value
```

常见形式：

- `uint16`，以毫米等整数单位保存；例如 2000 配合比例 `0.001` 后为 2 m。
- `float32`，通常直接以米保存。
- `0`、`NaN`、`Inf`，常表示没有可靠测量。

不能根据数值大小猜单位。程序应显式接收从原始单位到米的比例，并统一在三维几何接口中使用米。

## Z-depth 与 Range

- Z-depth：沿相机光轴方向的坐标 Z。
- Range：相机中心到三维点的欧氏距离。

针孔相机公式中的 `Z` 是 Z-depth。激光雷达射线距离通常更接近 Range。两者在图像中心附近接近，在视野边缘不同，不能不加说明地混用。

## 相机内参与投影

针孔相机内参矩阵：

```text
    [fx  0  cx]
K = [ 0 fy  cy]
    [ 0  0   1]
```

- `fx`、`fy`：以像素为单位的焦距。
- `cx`、`cy`：主点。
- `(u,v)`：图像坐标，u 是列方向，v 是行方向。

三维点投影到像素：

```text
u = fx × X/Z + cx
v = fy × Y/Z + cy
```

项目使用投影—反投影往返作为几何一致性检查。实验 010 的最大像素误差约为 `8.53×10⁻⁶`，说明公式、坐标顺序和数值实现一致。

注意 `torch.nonzero(mask)` 返回 `(v,u)`，而项目点云接口保存 `(u,v)`。如果不交换顺序，会把图像横纵坐标混淆。

## 从深度图到点云

对每个有效深度像素执行反投影，可以得到相机坐标系点云：

```text
depth image (H,W)
→ valid pixel coordinates (N,2)
→ depths (N,)
→ camera points (N,3)
```

常见点云形式：

- Organized Point Cloud：保持 `(H,W,3)` 图像结构，无效点保留占位。
- Unorganized Point Cloud：只保存有效点，形状为 `(N,3)`。

实验 010 使用无组织点云，并额外保存每个三维点对应的 `(u,v)`，方便回查原始像素、颜色或语义标签。

## 深度有效性与量程

反投影前应至少检查：

```text
isfinite(depth)
AND depth > 0
AND depth >= minimum_depth
AND depth <= maximum_depth
```

无效深度应被删除或明确保留为无效标记，不能自动替换为 `(0,0,0)`。原点在机器人坐标中可能是有效位置，伪造原点会污染中心、包围盒、障碍物和控制结果。

真实深度空洞常来自遮挡边界、反光、透明、低纹理、超出量程或传感器噪声。是否插值填补必须根据任务决定，不能默认所有空洞都应补齐。

## 使用语义 Mask 提取目标点云

语义 Mask 可以和有效深度条件组合：

```text
selection = (semantic_mask == target_class) AND valid_depth
```

然后只反投影目标像素。与矩形检测框相比，语义 Mask 能减少框内背景点，但仍会继承分割误差：

- 假阳性像素会引入背景点。
- 假阴性像素会造成目标点云缺失。
- 边界误差会混合不同深度表面。

实验 010 为隔离三维几何问题，使用已知正确 Mask。后续连接预测 Mask 时，应单独分析二维误差如何影响三维中心和范围。

## RGB-D 对齐、内参与时间同步

RGB Mask 能直接索引深度图，需要满足：

- RGB 与深度已经配准到同一像素网格。
- 图像尺寸一致或存在明确映射。
- 使用与深度图对应的相机内参。
- 时间戳足够接近。
- 裁剪、缩放、Letterbox 和畸变校正已同步处理。

如果分割模型使用缩放后的图像，而深度仍在原始分辨率，必须把 Mask 映射回深度坐标，或同步变换深度与内参。只调整数组尺寸而不调整内参会产生错误三维位置。

## 坐标系与 TF2

反投影结果首先属于相机光学坐标系：

```text
X right, Y down, Z forward
```

机器人底座常用：

```text
X forward, Y left, Z up
```

因此相机点不能直接作为机器人或世界坐标。实际系统需要根据采样时间使用 TF2：

```text
camera_optical_frame
→ camera_link
→ base_link
→ odom / world
```

坐标变换必须和深度时间戳匹配；机器人运动时使用错误时刻的 TF 会产生空间偏差。

## 点云后续处理

常见点云流程包括：

- Voxel Downsampling：降低点数和计算量。
- 离群点过滤：删除孤立噪声。
- 平面分割：去除地面、桌面或墙面。
- 聚类：分离不同目标。
- 法向量估计：描述表面方向。
- 三维中心、包围盒和抓取姿态估计。

这些算法应在任务需要时逐步引入。点云生成的单位、内参、有效性和坐标系如果错误，后续复杂算法也无法补救。

## 当前项目证据与知识边界

实验 010 已验证：

- 像素、Z-depth 和相机内参的反投影公式。
- 三维点到像素的投影往返一致性。
- 毫米深度缩放到米。
- `0`、`NaN`、`Inf` 与量程外深度过滤。
- 使用语义 Mask 提取正方形和圆形点云。
- 合成场景中点云位置、深度顺序和二维图像关系一致。

当前结果来自已配准合成 RGB-D 数据和正确 Mask。尚未验证真实相机标定、畸变、时间同步、TF2 点云转换、预测 Mask 误差传播、点云滤波和真实三维目标估计。

# SAC：经验回放、连续动作与闭环评价

## 快速复习

- Soft Actor-Critic（SAC）是适合连续动作的离策略（off-policy）Actor-Critic 方法。本项目的教学实现使用高斯策略、双 Q 网络、目标 Q 网络、经验回放和固定熵系数 `alpha`。
- 离策略的意思是：更新时能使用此前按别的行为策略采集的转移。**不等于离线 RL**；实验 040–041 的 SAC 仍不断与仿真环境交互并采集新转移。
- 训练损失正常下降，不足以证明闭环成功。评价需要固定任务、时限、动作选择方式和成功条件，并分开报告不同评价协议。
- 本项目的 200 步与 400 步评价只改变了时限；前缀轨迹相同，但成功数不同。较长时限揭示“慢”，不能称为策略改进。

## 1. SAC 解决什么问题

点机器人的动作是连续施力。PPO 第一轮使用离散动作，SAC 第一轮则直接学习连续动作分布。策略 `π(a|s)` 给出状态 `s` 下的动作分布；Q 网络 `Q(s,a)` 估计从该状态执行指定动作的后续软回报。训练时采样动作以探索；本项目评价时取确定性动作，减少测试时随机性的影响。

经验回放（replay buffer）保存 `(s, a, r, s_next, terminated, truncated)`。一次环境交互产生一条新转移，训练更新则能重复抽取旧转移。这里的“多次抽到”不等于“采到多种独立经验”：若回放池几乎没有负目标，即使反复抽样也不能凭空补出负目标经验。

## 2. 本项目的更新数据流

```text
从回放池抽样 → 计算下一状态软 Q 目标 → 更新双 Q 网络
             → 用 Q 评价策略采样动作并更新 Actor → 软更新目标 Q 网络
```

双 Q 网络取较小值，用来抑制 Q 值过高的风险；目标 Q 网络缓慢跟随在线 Q 网络。软 Q 目标可写成：

```text
y = r + γ × (1 - terminated) × [min(Q1_target, Q2_target) - α × log π(a_next|s_next)]
```

`r` 是本步奖励，`γ` 是折扣，`α` 控制熵项权重。真正到达终止状态时不再估计后续价值；单纯撞到评价/训练时间上限的 `truncated` 不等同于任务终止。本项目实现据此仍对时限截断状态做 bootstrap。Actor 更新的方向是提高采样动作的 Q，同时保留由 `α` 控制的随机性。上述数据流见 `src/robot_learning/sac_dataflow.py` 与 `src/robot_learning/sac_training.py`；它说明代码在算什么，不保证学到好策略。

## 3. 这一轮仿真教会我们怎样评价

实验 040 显示短训练下回放池的方向覆盖不足；实验 041 固定预算和目标距离序列，仅改变训练方向覆盖。三个训练种子的配对复验中，正方向单一组均为 `0/20`，双向组分别为 `6/20、6/20、3/20`（200 步时限）。方向覆盖有帮助，但还不能称为稳定闭环。

将同一批冻结策略的时限延至 400 步后，双向组分别为 `12/20、14/20、8/20`；固定比例控制器从 `2/20` 变为 `20/20`。新成功来自额外时间，而非新训练。仍失败的轨迹包括未靠近目标，以及到位却未同时降到 `0.10 m/s` 以内。因而至少要同时看：位置、速度、方向、成功所需时间，以及同任务的简单控制基线。不同任务集、训练预算或评价时限的数字不可直接混作单变量对照。

## 4. 离策略不等于离线

在线 SAC 可以一边训练一边尝试新动作、获取新数据，因而有机会发现回放池尚未覆盖的状态和动作。离线 RL（offline RL）在训练阶段只能用固定数据集，不能再向环境询问新动作的结果。如果数据里只有某些动作，Q 网络对未见动作的高估可能诱使策略选它；但固定数据集无法自动纠正这种估计。这是下一节要理解的核心困难，不应把“用了经验回放”误称为“已做离线 RL”。

## 限制与知识空白

本项目只验证了教学规模的一维仿真实现和固定评价协议；未完成 SAC 论文核心结果复现、系统超参数研究、真机部署或稳定双向到达。不能由这一轮结果判断 SAC 算法一般有效或无效。离线 RL 的数据支持范围、分布外动作与价值外推问题尚需单独学习和验证。

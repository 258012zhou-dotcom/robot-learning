# Linux 命令行基础

## 已掌握

- `~`：当前用户的主目录
- `.`：当前目录
- `..`：上一级目录
- `pwd`：显示当前目录
- `cd`：切换目录
- `ls -la`：查看文件、文件夹和隐藏内容
- `find . -maxdepth 2 -type d | sort`：查看一定层级内的文件夹
- `grep -n "关键词" 文件名`：在文件中搜索关键词，并显示行号

## 文件操作

- `cp 源文件 目标文件`：复制文件
- `mv 旧路径 新路径`：移动文件或重命名
- `rm 文件名`：删除文件
- `rmdir 文件夹`：删除空文件夹
- `chmod +x 文件名`：给脚本增加可执行权限
- `./脚本名`：执行当前项目中的脚本

## 搜索与查看

- `grep -n "关键词" 文件名`：搜索关键词并显示行号
- `find . -maxdepth 2 -type d | sort`：查看一定层级内的文件夹
- `less 文件名`：分页查看文件，按 `q` 退出
- `nano 文件名`：编辑文本文件

## 环境与进程

- `command -v 程序名`：查看程序实际使用的位置
- `conda activate 环境名`：激活 Conda 环境
- `ps`：查看进程
- `kill PID`：停止指定进程
- `Ctrl + C`：停止当前前台运行的程序

## 安全原则

- 删除前先确认目标路径，不随便使用 `rm -r`。
- 不对不认识的 PID 使用 `kill`。
- 运行 Python 项目前先确认已激活正确的 Conda 环境。
- 修改项目文件后，用 `git status` 检查改动。

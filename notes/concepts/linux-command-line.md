# Linux 命令行基础

位置：`~` 是主目录，`.` 是当前目录，`..` 是上一级。先用 `pwd` 确认位置，再用 `cd` 切换，`ls -la` 查看内容。

| 目的 | 常用命令 |
| --- | --- |
| 查看或搜索 | `less`、`rg`、`find` |
| 文件操作 | `cp`、`mv`、`rm`、`chmod +x` |
| 环境与运行 | `conda activate 环境名`、`./脚本名` |
| 进程控制 | `ps`、`kill PID`、`Ctrl+C` |

项目用法：运行实验或测试前激活 `robot_learning`；改动后用 `git status` 检查。删除前确认路径，不随意使用递归删除；不要停止不认识的进程。

命令默认在“当前目录”工作：先 `pwd`，再执行相对路径命令。`>` 会覆盖文件、`>>` 会追加文件；未确认目标前不要使用它们写入项目内容。

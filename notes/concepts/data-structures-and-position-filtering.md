# 数据结构与位置过滤

## 核心概念

| 结构 | 特点与本项目中的用途 |
| --- | --- |
| `list` | 有顺序、可修改；JSON 的二维位置读入后常先表现为列表 |
| `tuple` | 有顺序、不可修改；`PointRobotConfig` 用二维元组保存已验证的位置和速度 |
| `dict` | 键值映射；JSON 配置读取后是字典，通过字段名取得参数 |
| `set` | 不重复且不保证顺序；适合成员检查或去重，本项目当前没有必要使用它保存轨迹 |
| `deque` | 双端队列；在两端添加或删除通常是 O(1)，适合保留固定数量的最新位置 |

`PositionBuffer` 内部使用 `deque(maxlen=capacity)`。当缓冲区已满时，加入新观测会自动丢弃最早的观测；`mean()` 对缓冲区内位置按坐标求平均。

对最近 `N` 个二维观测 \(z_i\)，滑动平均为：

```text
estimated_position = (z_1 + z_2 + ... + z_N) / N
```

二维 RMSE（Root Mean Squared Error）用于评价估计与真实位置的整体误差：

```text
RMSE = sqrt(mean(||estimated_position - true_position||^2))
```

数值越小，代表整体位置估计通常越接近真实位置。

## 项目中的实际证据

- `PositionBuffer.append()` 接受形状为 `(2,)` 的位置，并复制输入，防止外部数组被修改后影响缓冲区。
- 容量为 2 时依次加入 `[0, 0]`、`[2, 0]`、`[4, 0]`，缓冲区只保留最近两个点，平均值为 `[3, 0]`。
- 实验 002 使用容量为 5 的缓冲区，对 100 个带噪静止位置观测进行过滤。
- 固定种子下，原始观测 RMSE 为 `0.6224`，过滤后 RMSE 为 `0.2543`，说明该条件下滑动平均降低了随机噪声。

## 常见错误

- 用普通 `list` 从开头频繁删除旧元素：每次移动后续元素通常是 O(n)，不如 `deque` 适合滑动窗口。
- 忘记复制可变的 NumPy 数组：外部修改会意外改变已保存的历史位置。
- 对空缓冲区求均值：没有可平均的数据，`PositionBuffer.mean()` 会抛出 `ValueError`。
- 将“过滤必然更好”推广到所有情况：对运动目标，窗口中较早的观测会使估计落后于真实位置，形成过滤延迟（filter lag）。
- 只比较单一步的误差：应使用 RMSE 等汇总指标比较整段观测。

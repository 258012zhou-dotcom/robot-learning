# 数据结构与位置过滤

| 结构 | 关系与用途 |
| --- | --- |
| `list` | 有序、可修改；JSON 中的位置常以列表读入 |
| `tuple` | 有序、不可修改；已验证配置用它保存二维位置和速度 |
| `dict` | 键值映射；JSON 配置按字段名取值 |
| `set` | 去重或成员检查；不适合保存有顺序的轨迹 |
| `deque` | 两端操作通常 O(1)；适合固定长度的滑动窗口 |

`PositionBuffer` 用 `deque(maxlen=capacity)` 保存最近位置：加入新观测后，`mean()` 计算坐标平均。窗口满时最早观测自动丢弃。

滑动平均降低静止目标的随机噪声：

```text
estimate = 最近 N 个观测的平均值
RMSE = sqrt(mean(||estimate - true_position||²))
```

项目证据：实验 002 使用容量 5 的 `PositionBuffer`；固定种子下，原始 RMSE 为 `0.6224`，过滤后为 `0.2543`。

重要提醒：不能对空缓冲区求均值；窗口开始时少于 `capacity` 个样本，平均值还在“预热”；保存 NumPy 数组时要复制，避免外部修改历史值；目标运动时，窗口越大通常越平滑，但延迟也越明显。

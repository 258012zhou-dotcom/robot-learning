# Linux 进程、设备与网络基础

## 进程

每个进程拥有 PID、父进程、状态、环境变量和标准输入输出。优先通过正常退出、`Ctrl+C` 或 `SIGTERM` 停止程序，`SIGKILL` 只作为最后手段。

## 设备

Linux 通常通过 `/dev` 下的字符设备访问摄像头、串口和输入设备。设备存在但无法访问时，应检查文件权限和 `video`、`dialout` 等用户组，不应默认用 root 运行程序。

## 网络

网络通信由协议、IP 地址和端口确定。`127.0.0.1` 只表示当前网络环境自身；Windows、WSL、容器和远程机器人中的 localhost 可能不是同一个系统。

TCP 提供连续字节流，不保留消息边界。实验使用换行符标记一条 JSON 消息结束。

本地实验中，服务端监听 `127.0.0.1:50007`，客户端使用临时端口连接并传递位置样本。

# Codex CLI 基础复习笔记

这份笔记用于区分 Ubuntu 终端与 Codex 交互界面，并记录当前阶段最常用的操作。学习具身智能开发时，我们会频繁使用终端管理项目，也会用 Codex 阅读、解释和修改代码，因此先分清“命令应该在哪里输入”很重要。

## Ubuntu 终端与 Codex 界面

### Ubuntu 命令行

看到类似下面的提示符时，说明当前位于 Ubuntu 命令行（Command Line）：

```text
zxd@zhou:~/AI_Project/robot-learning$
```

`$` 前面通常显示用户名、计算机名和当前目录。在这里可以输入 Linux 命令，也可以输入：

- `codex`：启动 Codex，进入 Codex 交互界面。
- `codex resume`：打开已保存聊天的选择菜单，以便继续之前的聊天。

### Codex 交互界面

运行 `codex` 后就进入 Codex。在这里主要输入自然语言任务，例如“解释这个测试为什么失败”。以 `/` 开头的命令属于 Codex 内部命令，例如 `/resume` 和 `/new`，不要把它们直接输入 Ubuntu 命令行。

可以这样记：

| 所在位置 | 输入示例 | 含义 |
| --- | --- | --- |
| Ubuntu 命令行 | `codex` | 启动 Codex |
| Ubuntu 命令行 | `codex resume` | 启动 Codex 并选择以前的聊天 |
| Codex 内部 | `/resume` | 在 Codex 中选择并恢复聊天 |
| Codex 内部 | `/new` | 在当前 Codex 会话中新建聊天 |

## 当前常用命令

以下命令都在 Codex 内使用：

| 命令 | 作用 |
| --- | --- |
| `/new` | 新建一个聊天，不影响原聊天记录 |
| `/resume` | 从列表中选择并继续已保存的聊天 |
| `/rename` | 给当前聊天命名或改名，方便以后查找 |
| `/status` | 查看当前聊天、上下文使用情况和限制等状态信息 |
| `/permissions` | 查看或调整 Codex 的权限与审批方式 |
| `/diff` | 查看 Git 差异，包括已暂存、未暂存和未跟踪的改动 |
| `/exit` | 退出 Codex，返回 Ubuntu 命令行 |
| `@文件名` | 搜索并把工作区中的文件加入当前问题的上下文 |

例如，输入 `@README.md` 可以让 Codex 在回答当前问题时重点参考该文件。它不是修改文件的命令。

## 菜单操作

Codex 出现命令、聊天或权限选择菜单时，可以使用：

| 按键或操作 | 作用 |
| --- | --- |
| `↑`、`↓` 方向键 | 上下移动并选择菜单项 |
| `Enter` | 确认当前选择 |
| `Esc` | 取消或返回上一层 |
| 输入文字 | 筛选菜单内容，快速找到目标项 |

如果列表较长，先输入聊天名或命令的一部分，通常比逐项移动更快。

## 我当前的使用原则

1. 保留一个主聊天，命名为 `robot-learning-main`，用于学习路线、阶段安排和项目整体问题。
2. 一个完整实验可以新建一个独立聊天，让实验背景、代码修改和验证记录集中在一起。
3. 普通操作保持 **Workspace (Ask for approval)**，让 Codex 只能在工作区范围内操作，并在需要时请求批准。
4. 不使用 **Danger Full Access**、`yolo` 或任何绕过审批与沙箱（Sandbox）的方式。这些模式会减少重要的安全保护。
5. Codex 修改文件后，先运行 `/diff` 检查修改内容，再决定是否测试、保留或提交。

检查 `/diff` 时，至少确认：

- 修改的是不是预期文件；
- 有没有删除原本需要的内容；
- 有没有意外加入密码、令牌、大型数据或生成文件；
- 代码和说明是否符合当前实验目标。

## 暂时不需要掌握

下面的命令目前只需要知道“它们存在”，不要求现在记住或使用：

| 命令 | 简单认识 |
| --- | --- |
| `/fork` | 从已有聊天复制出一个新的分支聊天 |
| `/compact` | 压缩较长聊天的上下文，以便继续工作 |
| `/apps` | 查看或使用可连接的应用（Apps） |
| `/plugins` | 查看或管理扩展能力的插件（Plugins） |

这些功能在聊天变长、需要尝试不同方案或需要连接外部工具时才更有价值。当前阶段先熟练掌握终端与 Codex 的区别、会话管理、权限控制和 `/diff` 检查；以后实际需要时再学习这些命令。

# 状态估计与一维 Kalman Filter

## 快速复习

- 真实状态客观存在但通常无法直接准确获得；传感器给出观测，估计器给出状态估计及其不确定性。
- 状态估计循环由预测（Prediction）和更新（Correction）组成。
- `P` 是当前估计方差，`Q` 是运动模型的过程噪声方差，`R` 是传感器测量噪声方差。
- Kalman Gain 决定更相信预测还是观测：预测越不确定，越依赖观测；传感器越不可靠，越依赖模型。
- 方差表示估计器自己的置信程度，不等于已经知道的真实误差。错误的模型、坐标系、时间戳或噪声参数会造成“错误但自信”的估计。

## 状态、观测与估计

需要区分：

- `x`：真实状态（True State），例如机器人真实位置。
- `z`：观测（Measurement），例如视觉定位或 GPS 测得的位置。
- `x_hat`：估计（Estimate），算法根据模型和观测推断的位置。
- `P`：估计方差（Estimate Variance），算法对 `x_hat` 的不确定性。

真实机器人不能直接读取“完美的 x”。仿真器可能提供 ground truth，但它不等同于真实传感器数据，也不应在部署时作为策略的隐式输入。

## 一维预测

当前模型只估计一维位置，速度被视为已知输入：

```text
x_hat_pred = x_hat + velocity × dt
P_pred = P + Q
```

预测依靠运动模型向前推算。每次预测都加入过程噪声 `Q`，表示轮胎打滑、执行误差、模型简化等未知因素，因此只预测而没有新观测时，通常会越来越不确定。

当前代码把 `Q` 简化为每次预测固定增加的方差。真实多维过滤器会根据 `dt`、状态转移矩阵和噪声模型传播协方差。

## 一维更新

收到位置观测 `z` 后：

```text
innovation = z - x_hat_pred
K = P_pred / (P_pred + R)
x_hat = x_hat_pred + K × innovation
P = (1 - K) × P_pred
```

Innovation（创新或残差）描述观测与预测的差异。Kalman Gain `K` 是本次修正权重：

- `K` 接近 0：主要保留预测。
- `K` 接近 1：主要跟随观测。
- `P_pred` 增大时，`K` 通常增大。
- `R` 增大时，`K` 减小。

数值例子中，预测为 `1.0`、预测方差为 `1.2`，观测为 `1.8`、测量方差为 `0.3`，得到 `K=0.8`、更新估计 `1.64`、更新方差 `0.24`。

## P、Q、R 的工程含义

### P：当前估计不确定性

初始 `P` 大，表示不知道初始位置，会在启动阶段快速接受传感器；初始 `P` 小，表示较相信初始状态。经过多轮更新后，长期行为通常更多由 `Q`、`R` 和数据决定。

### Q：过程噪声

`Q` 大表示运动模型不可靠，估计器更愿意使用观测；响应更快，但也可能跟随观测噪声。`Q` 小表示相信运动模型，结果更平滑，但模型偏差可能积累成漂移。

机器人中的过程噪声可能来自轮胎打滑、轮径误差、地面变化、控制误差和未建模动力学。

### R：测量噪声

`R` 大表示传感器不可靠，Kalman Gain 较小；`R` 小表示更相信观测。测量噪声可能来自视觉检测波动、遮挡、LiDAR 匹配误差、标定误差和时间不同步。

`R` 可以通过静止采样和误差统计初步估计；`Q` 可以根据运动模型残差和工程经验估计，再使用独立数据验证。调参不能代替修正错误坐标系、时间戳或传感器数据。

## 当前项目实验

演示使用真实速度 `1.0 m/s`，但运动模型错误地使用 `0.9 m/s`，因此纯预测会持续落后。外部位置观测没有持续偏差，但每一步都有确定性的正负噪声。

实际结果：

```text
Measurement RMSE: 0.5060
Prediction RMSE:  0.6205
Kalman RMSE:      0.2538
```

平衡设置 `Q=0.05`、`R=0.25` 的 RMSE 最低。过度相信模型时，最终 Gain 约为 `0.072`，无法及时修正速度偏差；过度相信传感器时，Gain 约为 `0.954`，估计基本跟随测量抖动。

5 个单元测试验证：

- 预测更新位置并增加不确定性。
- 数值更新结果与手算一致。
- 高测量噪声产生更小 Gain。
- 重复观测降低估计方差。
- 非法方差被拒绝。

## 与 ROS 2 系统的关系

当前项目已经具备：

```text
编码器 → /odom → 运动预测
相机或 LiDAR → 外部观测
```

真实系统通常还会加入 IMU，并由现成融合组件输出连续状态。常见 TF 结构是：

```text
map/world → odom → base_link → sensor frames
```

本轮没有自行实现二维 EKF、SLAM 或 ROS 多传感器融合节点。当前目标是能理解并诊断预测、观测、协方差和融合结果；以后项目确实需要时，再学习 `robot_localization`、EKF/UKF 或视觉惯性估计。

## 适用条件与限制

标准 Kalman Filter 假设系统近似线性、噪声可用高斯分布及正确协方差描述。真实机器人常含非线性、异常值、相关噪声和时变误差，因此可能需要 EKF、UKF、粒子滤波、鲁棒估计或优化方法。

本轮标记为“状态估计基础完成”只代表能够解释并验证最小预测—更新流程，不代表已经掌握完整定位与传感器融合。

本轮验证结果为：状态估计 5 个单元测试通过；ROS 2 工作空间完整回归测试汇总为 55 tests、0 errors、0 failures、1 skipped。

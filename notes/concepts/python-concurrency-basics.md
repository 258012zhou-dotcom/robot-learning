# Python 并发基础

## 三种并发方式

- 进程拥有独立内存，适合 CPU 密集任务和故障隔离。
- 线程共享进程内存，适合阻塞 I/O 和后台任务，但需要防止竞态条件。
- `asyncio` 在等待时协作切换，适合大量网络或 I/O 任务，不会自动加速 CPU 计算。

## 线程安全的数据流

实验 003 使用：

```text
生产者线程 → Queue → 主线程消费者

Queue 在线程间安全传递数据，并提供有限容量产生背压。
Event 用于发送停止请求。
None 作为结束标记，通知消费者数据流已经结束。
join() 等待线程实际退出。
time.monotonic() 适合测量间隔和超时。

```md
## 进程与异步实测

多进程示例中，主进程与计算进程 PID 不同，计算结果通过 `multiprocessing.Queue` 返回。

异步示例中，两个任务运行在同一 PID。任务在 `await` 时让出执行权，因此两个等待任务总耗时接近最长单个任务，而不是等待时间之和。

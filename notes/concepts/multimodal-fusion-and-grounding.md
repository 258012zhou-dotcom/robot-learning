# 多模态融合与语言条件视觉定位

## 快速复习

- 表示（Representation）把图像和文字转换成特征；对齐（Alignment）让相同语义跨模态接近；融合（Fusion）让两种模态共同影响输出；Grounding 把语言概念对应到具体图像区域或空间目标。
- 双编码器适合全局检索，空间 Grounding 还需要保留局部 Visual Tokens 和位置。
- 仅视觉不知道任务要哪个物体，仅语言不知道物体在哪里；单模态消融是证明融合必要性的关键证据。
- Cross-Attention 可把语言表示作为 Query、视觉区域作为 Key/Value，输出语言条件的空间权重。
- Attention 是可调试的中间证据，但不能自动等同于因果解释。

## 从全局对齐到空间 Grounding

实验 014 使用图像和文本的全局向量完成语义检索：

```text
图像 → 图像编码器 → 整图向量
文字 → 文本编码器 → 整句向量
```

这种结构能回答“整张图与哪段文字最匹配”，但一张图包含多个物体时，一个全局图像向量未必保留每个物体的位置。

空间定位需要让视觉编码器输出区域 Token：

```text
visual_tokens.shape = (N, P, D)
```

其中 `N` 是 batch 大小，`P` 是图像区域数量，`D` 是特征维度。文本编码器输出每条指令的 Query：

```text
language_query.shape = (N, D)
```

每个视觉区域与语言 Query 的相关性为：

```text
score[n, p] = dot(visual_tokens[n, p], language_query[n]) / sqrt(D)
```

`dot` 是点积，`sqrt(D)` 是 D 的平方根。对同一张图的 P 个区域分别打分，分数越大，表示该区域与指令越匹配。

经过 Softmax 得到区域权重，再用区域中心坐标加权求和：

```text
weight[n] = softmax(score[n])             # 每张图的区域权重之和为 1
predicted_center[n] = Σ_p weight[n, p] × region_center[p]
```

`Σ_p` 表示遍历所有区域后求和；`region_center[p]` 是第 p 个区域的二维中心坐标。比如两个中心为 `(0, 0)`、`(1, 0)`，权重为 0.2、0.8，预测中心就是 `(0.8, 0)`，不是直接选中第二个中心。

这是一种可微分 Soft-Argmax：训练误差可以通过坐标预测、Attention、视觉特征和文本特征反向传播。

## 常见融合方法

- 特征拼接：实现简单，适合小型结构化输入，但交互较粗。
- FiLM：语言生成缩放与偏移参数，条件调制视觉特征。
- Cross-Attention：一类模态作为 Query，主动读取另一类模态的 Token，适合视觉问答、Grounding 和语言条件策略。
- 晚期融合：多个模型先独立预测，最后组合结果，模块化强但细粒度交互有限。

融合层并不保证语义已经正确对齐。真正的对应关系来自配对数据、训练目标以及能够排除捷径的评价设计。

## 为什么需要单模态消融

如果模型只看图也能完成任务，可能是目标总在固定位置；如果只看文字也能完成，可能是每个类别位置固定。此时高准确率不能证明多模态推理。

实验 016 随机选择目标和位置，并在每个场景放置三个唯一概念。测试结果：

- 固定中心：`35.67%`，平均中心误差 `0.3149`。
- 仅视觉：`29.00%`，平均中心误差 `0.2830`。
- 仅语言：`34.33%`，平均中心误差 `0.3176`。
- 多模态：`100.00%`，平均中心误差 `0.0225`。

前三种方法接近三选一机会水平，多模态方法明显胜出。这比单独报告多模态准确率更能说明融合确实提供了必要信息。

## 与机器人系统的接口

实验输出的是归一化二维图像坐标。真实机器人还需要：

1. 相机内参和深度把像素反投影到相机坐标系。
2. TF2 外参把目标转换到机器人或世界坐标系。
3. 状态估计处理时间延迟和观测噪声。
4. 运动规划与控制把空间目标转成安全动作。
5. 执行后重新观测，形成闭环验证而不是一次性开环动作。

## 当前边界

- 固定文本模板不能代表自然语言泛化。
- 合成图形不能代表真实视觉域。
- 唯一概念避免了语言歧义，真实场景需要指代消解或主动澄清。
- Attention 热图可检查模型关注区域，但不能单独证明模型的内部因果推理过程。
